# Regulatory source register

## Purpose and use

This register preserves the user's known controlled source set and verified routing baselines, including an EAEU checkpoint added on **2026-09-04**, a dedicated global QRM routing checkpoint added on **2026-09-29**, and a dedicated PQR/APR checkpoint added on **2026-09-30**. It is not a frozen declaration of current law. For any currentness-dependent answer, open the regulator's official source or current index again and record the access date.

Use exact titles and filenames to locate controlled copies. A controlled copy proves only the text and version it contains. If the official source has changed, use the official current source for status and explain the relationship to the user's copy.
