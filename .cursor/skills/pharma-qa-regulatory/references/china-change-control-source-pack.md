# China change-control source pack

## Purpose

Use this index to select the minimum relevant controlled source for China pharmaceutical change-management work. The PDFs in `references/regulations/china-change-control/` are user-provided controlled copies. Do not treat their presence in this Skill as proof that they are currently effective or unsuperseded. For currentness-dependent conclusions, verify against the official NMPA/CDE source.

## Selection rules

- For a general China post-marketing change-control question, start with `《药品上市后变更管理办法（试行）》（国家药监局 2021年 第8号）.pdf` and add the applicable technical guideline.
- For MAH/contract-manufacturing responsibility or quality-agreement interfaces, add `《药品上市许可持有人落实药品质量安全主体责任监督管理规定》.pdf`.
- For clinical-development CMC changes, use the innovative-drug clinical-trial pharmaceutical-change guideline; for protocol amendments, use the clinical-trial protocol-change guideline.
- For changes during application review, use the registration-review-stage change procedure.
- For marketed-product CMC changes, use the marketed chemical-drug pharmaceutical-change guideline; add PACMP guidance when a prospective post-approval change management protocol is relevant.
- For marketed-product clinical changes, use the marketed chemical/biological clinical-change guideline.
- When multiple related changes occur, assess cumulative/interrelated impact and follow the stricter applicable technical pathway when the controlled source requires or supports that approach.
- Do not quote a source as current merely because it is bundled. Confirm publication/status/effective date from the official regulator when currentness matters.
