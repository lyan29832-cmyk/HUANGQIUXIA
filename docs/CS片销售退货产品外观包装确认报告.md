# 销售退货产品（CS片，1盒）外观包装确认报告

## 1. 概述

药业有限责任公司（以下简称药业）于2026年8月18日收到MAH质量管理部下发的F-SMP-01-80-001-03 V2《退货申请表》。退货产品为CS片1盒，批号20250822，由广东京卫医药有限公司退回。

退货原因：《退货申请表》载明，患者购药时怀疑药盒被拆开，不敢服用；经沟通后为患者更换1盒CS片，患者原购买的那盒CS片按退货处理。

质量保证部依据《退货申请表》上MAH质量受权人“按体系流程进行外观包装确认”的意见，于2026年8月18日收货后，按退货管理相关规程对该盒产品进行外观包装确认。确认所依据的沟通信息包括2026年7月28日及后续退货沟通记录（恒金堂药房、销售及患者侧反馈）。

## 2. 退货产品外观包装确认

### 2.1 生产环节

查阅该批次CS片批生产记录：外包装工序按《CS生产工艺规程》执行，过程检查记录中外观检查结果为符合规定。批记录未见该批次外包装工序不合格、返工或偏差放行的记载。

### 2.2 仓库发货环节

发货记录显示，该盒所属产品以整箱出库，由仓管员整箱打包发运。发货记录未见该箱拆箱后单盒复核或单盒发运的记载。

### 2.3 药店入库及销售出库环节

该盒经广东京卫医药有限公司流向恒金堂药房。药店收货后至患者购药前，未检索到该药店就本盒或本批次CS片提出的包装破损类质量投诉或退货申请。

2026年7月28日沟通记录载明：

1. 恒金堂药房反馈，患者当日购药时怀疑药盒已被拆开，不敢服用，提出换货。
2. 经询问门店，门店反馈该盒药品出库交付时外包装完好（沟通原文为“出库是好的”）。沟通记录中未附监控复核结论，本次不以监控影像作为确认依据。
3. 按内部处理意见，由销售与患者再次沟通；若仍需换货，由销售当面换货并收回原盒。后续已完成换货，原盒按退货收回。
4. 后续沟通中，相关人员询问是否当面拆开药盒，回复为否，并称患者拿回后即发现药盒呈打开状态。沟通中另有“上次也是一样”的表述，该表述未经核实，不作为本盒外观确认的判定依据。

上述信息表明：在已收集的记录范围内，药店出库交付前无该盒包装异常的记载；包装异常的发现时点为患者取得药品之后。

### 2.4 退货产品外观确认

2026年8月18日对收回的1盒CS片（批号20250822）进行目视检查，结果如下：

1. 盒盖翻盖未完全扣合到位，盒口张开，不呈闭合状态。
2. 盒盖卡扣已脱落。
3. 盒子两端可见轻微折痕。

上述外观与未经开启的完好外包装状态不一致，符合包装开启后的状态特征。检查照片见附件1-1。

本次确认范围为该盒外包装外观，未将内包装完整性、药品性状等作为本次外观包装确认的判定项。

## 3. 总结

综合生产记录、仓库发货记录、药店出库沟通记录及退货后目视检查结果：

1. 生产过程检查记录、整箱发运记录及药店出库反馈，均未记载该盒在交付患者前外包装异常。
2. 退货沟通显示，包装异常系患者取得药品后发现；门店反馈出库交付时外包装完好。
3. 收回产品的现况为盒盖未扣合、盒口张开、卡扣脱落、两端有轻微折痕，已不具备完好未开封包装的外观条件。

据此，该盒CS片不能按完好合格品退入可销售库存。建议按退货管理规程作为已开封退货产品作报废处理。

本次确认仅针对该1盒退货产品的外观包装。沟通中提及的既往类似情况，如需核实，应另案收集证据后处理。
