### 3.3 证据层级与证明范围

为确保论证边界清晰、避免不同类型证据被不当外推，本报告将支持性证据按证明范围分层如下：

| 证据层级 | 内容 | 能证明什么 | 不能单独证明什么 |
|---|---|---|---|
| A. 过程控制与历史运行 | SOP执行、温湿度与暴露时限、QA监督、偏差/OOS回顾 | 分装操作受控，未见与密封失效、吸湿结块直接相关的异常事件 | 不能证明可沿用原厂有效期 |
| B. 回顾性近/过效期检验 | 聚维酮K30、乳糖、微晶纤维素、羧甲淀粉钠在分装包装形式下的近效期/过效期检验 | 分装包装形式具有一定长期质量保持能力 | 批次与时间点有限，不能替代系统稳定性研究 |
| C. 实验室吸湿性实验 | 聚维酮K30、羧甲淀粉钠在设定湿度条件下的吸湿行为及质量/功能影响 | 在45%–65% RH及实际分装暴露窗口内，过程吸湿风险可控；为不强制执行供应商≤40% RH建议提供科学依据 | 不能直接等同于分装后长期贮存有效期/使用期限 |
| D. 制剂对比研究 | 分包装辅料与未分包装辅料所产西达本胺片：崩解、溶出、硬度、含量均匀度、稳定性对比 | 分装过程及现行控制未对制剂关键质量属性造成不可接受影响 | 不能替代辅料自身分装后使用期限的建立 |
| E. 前瞻性稳定性研究（CAPA） | 分包装辅料稳定性研究 + 西达本胺片持续稳定性考察 | 建立分装包装形式下科学使用期限的决定性依据 | — |

本报告结论遵循以下原则：

1. **A+B** 用于支持风险趋势与历史可接受性判断；
2. **C** 用于支持分装过程湿度控制策略（45%–65% RH）的科学性；
3. **D** 用于支持“分包装辅料用于生产对西达本胺片质量无不可接受影响”；
4. **E** 用于正式建立分装后使用期限；在E完成前，不以沿用原厂有效期作为控制策略。

### （修订）2、物料受潮、结块、氧化、降解风险

#### （1）聚维酮K30

| 风险因素 | 风险分析 | 控制措施 |
|---|---|---|
| 受潮/引湿性 | 聚维酮K30具有强引湿性，在暴露环境中会迅速吸收水分，可能导致粉体结块、变黏。供应商提出分包装过程宜控制湿度在40%以下；本公司分装环境按45%–65% RH控制，与厂家建议存在差异，需以科学数据评估该差异是否导致不可接受影响。 | 见下方“过程控制 + 实验室吸湿性实验 + 后续措施” |
| 结块 | 吸湿后表面溶解形成黏性膜，颗粒间粘连，导致流动性下降，可能影响后续称量和混合均匀度。 | 同上 |
| 氧化/降解 | 聚维酮K30本身化学稳定性较好，常温下不易氧化降解；大量吸水后长期贮存可能增加微生物风险。 | 同上 |

**厂家建议与本公司条件差异说明**

供应商提示分包装过程湿度宜≤40% RH。本公司分装在独立称量间和层流罩下操作，环境温度控制在18–26℃，相对湿度控制在45%–65%。该差异属于已知过程风险，不能仅以“公司环境标准如此”予以豁免，须结合实际暴露时限、密封控制及实验室吸湿性实验综合评估。

**实验室吸湿性实验（证据层级C）**

为评估在45%–65% RH条件下短时暴露对聚维酮K30质量的影响，本公司开展了实验室吸湿性实验（详见附件〔附件编号：聚维酮K30吸湿性实验报告〕）。

- 实验条件：〔温度，如25℃±2℃〕；相对湿度〔40%（对照）、45%、55%、65% RH〕。
- 取样时间点：〔0、15、30、60 min…〕（覆盖并适当严于实际分装暴露时限）。
- 考察项目：〔外观/性状、水分、〔溶液粘度或其它功能相关指标，如有〕、必要时微生物相关评估〕。

**主要结果：**

1. 在实际分装暴露时限范围内（本公司历史数据：原包装平均暴露16–54分钟，单袋最大暴露4–10分钟），于45%–65% RH条件下，聚维酮K30〔水分由X%变化至Y%，仍符合质量标准/内控要求；外观未见结块、变黏等异常；功能相关指标未见不可接受变化〕。
2. 与40% RH对照相比，〔简述：差异幅度、是否具有实际质量意义、是否仍在可接受范围〕。
3. 暴露后按现行分装内/外包装密封放置〔时间〕，〔水分及关键指标保持稳定/未见持续劣变〕。

**过程控制数据（证据层级A）**

严格按照SOP-PR-200-012《生产物料分包装标准操作规程》执行，在独立称量间和层流罩下操作；分装后及时进行〔热合密封/现行真实密封方式〕，并对分包装后每袋外包装进行热封质量检查，确保网纹清晰、平整、无褶皱，整体密封性良好；分装前后清场；QA全程监督环境参数、操作时限与密封操作。

自实施分包装以来，已完成10批次聚维酮K30分包装。实际运行数据显示：称量间温度20.0℃–23.7℃、湿度50%–58%；辅助备料间温度19.5℃–23.6℃、湿度50%–59%；原包装平均暴露16–54分钟，单袋最大暴露4–10分钟。具体数据详见附表一。

**综合判断（仅针对过程风险）**

在现行短时暴露、及时密封及外包装热封确认的控制策略下，实验室吸湿性实验支持：**聚维酮K30分装过程维持45%–65% RH控制可接受，不必将分装房间湿度强制调整至≤40% RH**。该结论仅支持过程控制策略，不构成分装后长期沿用原厂有效期的依据。

**后续措施**

1. 开展分包装辅料稳定性研究，建立辅料分包装后的使用期限；
2. 对分包装辅料生产的西达本胺片进行长期/持续稳定性考察；
3. 在稳定性研究完成前，对高风险辅料实施投产前抽检（见第三部分CAPA）。

### （修订）风险2小结

基于辅料理化性质分析，上述6种辅料在常温密封条件下化学性质总体稳定，氧化与降解风险较低；主要质量风险集中于受潮与结块，其中聚维酮K30、羧甲淀粉钠风险较高。

现有控制措施包括：严格执行SOP-PR-200-012，温湿度监控，限制暴露时限，分装后及时密封并检查外包装热封质量，QA全程监督。历史运行未见因分装密封不良导致的受潮、结块、污染等相关异常。

针对供应商“分包装湿度≤40% RH”建议，本公司以聚维酮K30、羧甲淀粉钠实验室吸湿性实验证明：在**实际分装暴露窗口内**，于**45%–65% RH**条件下，辅料关键质量属性未发生不可接受变化。因此，分装过程可继续维持现行环境湿度控制策略；对高湿风险的控制重点由“强制降低房间湿度”转为“短时暴露 + 密封屏障 + 关键项目监控 + 分装后使用期限管理”。

除此之外，还需增加以下控制措施：

- 选择风险较高的聚维酮K30、羧甲淀粉钠，在每批西达本胺片称量备料工序中取部分样品进行检验，确认分包装辅料在投料生产前的质量状况；
- 开展分包装辅料稳定性研究，建立辅料分包装后的使用期限；
- 对分包装辅料生产的西达本胺片进行持续稳定性考察。

### 4、分包装辅料对制剂产品质量影响评估（证据层级D）

#### 4.1 评估目的

分装过程即使未导致辅料检验项目立即不合格，仍可能通过水分、粉体学性质或功能相关属性的细微变化，影响下游制剂的崩解、溶出、硬度或含量均匀度等。为闭环评估该风险，本公司比较“使用分包装辅料生产的西达本胺片”与“使用未分包装（原厂包装直接投料）辅料生产的西达本胺片”的关键质量属性。

#### 4.2 对比设计

| 项目 | 内容 |
|---|---|
| 对比组别 | 组别A：未分包装辅料生产批次；组别B：分包装辅料生产批次 |
| 批次信息 | 组别A：〔批号〕；组别B：〔批号〕 |
| 处方与工艺 | 同一处方、同一生产工艺及质量控制标准 |
| 对比项目 | 崩解、溶出、硬度、含量均匀度；稳定性（〔条件及时间点〕） |
| 数据来源 | 〔检验报告编号 / 稳定性报告编号〕 |

#### 4.3 主要结果

1. **崩解**：两组结果均符合质量标准，〔组间差异描述：如无明显系统性延长/差异处于历史波动范围〕。
2. **溶出**：两组溶出行为〔一致/相似〕，〔关键时间点溶出量差异处于可接受范围，未见分装辅料导致的溶出下降趋势〕。
3. **硬度**：两组硬度〔相当〕，〔未见由辅料吸湿或粉体学变化引起的异常偏软/偏硬〕。
4. **含量均匀度**：两组均符合规定，〔未见混合均匀性受损迹象〕。
5. **稳定性**：在〔考察条件〕下至〔时间点〕，两组样品在性状、溶出、含量、有关物质、微生物限度等关键指标方面〔均符合标准，且未见由辅料分装引入的不良趋势〕。

详细数据见附件〔附件编号：分包装与未分包装辅料所产西达本胺片质量对比报告〕。

#### 4.4 结论边界

上述对比表明：在现行分装与生产控制下，**使用分包装辅料生产的西达本胺片，与使用未分包装辅料生产的产品相比，关键质量属性无不可接受差异**，支持“分装过程风险可控、分包装辅料可用于西达本胺片生产”的判断。

但必须明确：

1. 本对比属于**下游制剂确认证据**，证明的是“对产品质量的影响可接受”；
2. 本对比**不能替代**辅料在分装包装形式下的自身稳定性研究；
3. 本对比**不能直接证明**分装后可继续沿用供应商出厂有效期；
4. 辅料分装后使用期限仍须按照本报告第三部分CAPA，通过分装包装形式下的稳定性研究建立。

### （新增）风险评估结果与CAPA衔接说明

综合本报告证据链：

| 已回答的问题 | 对应证据 | 结论状态 |
|---|---|---|
| 分装操作是否受控？ | 证据A | 可接受 |
| 分装包装是否具备一定保护能力？ | 证据B | 有支持，但强度有限 |
| 45%–65% RH下短时分装是否导致高引湿辅料不可接受吸湿/功能损失？ | 证据C | 可接受（K30、SSG） |
| 分包装辅料是否影响西达本胺片关键质量属性？ | 证据D | 未见不可接受影响 |
| 分装后可以沿用多久？是否等于原厂有效期？ | 证据E（进行中） | **尚未建立，不得简单沿用原厂有效期** |

因此，CAPA分为三个层次，避免将“过程可接受/制剂无影响”误等同于“可沿用原厂有效期”：

1. **即时控制（桥接措施）**：对聚维酮K30、羧甲淀粉钠实施投产前检验，降低贮存阶段残留风险在生产端的漏检可能；
2. **期限建立（核心措施）**：开展分包装辅料稳定性研究，科学设定分装后使用期限；
3. **下游确认（支持措施）**：对使用分包装辅料生产的西达本胺片开展持续稳定性考察。

实验室吸湿性实验与制剂对比研究属于**已完成的支持性验证**，分别固化过程湿度策略与产品质量无不可接受影响的结论；**不替代**分包装辅料稳定性研究，也不作为继续沿用原厂有效期的依据。

### 四、结论

1. **关于有效期管理**  
   分装改变了辅料原厂包装与密封体系。在未经分装包装形式下充分稳定性验证的情况下，直接沿用厂家有效期科学依据不足。本公司接受Nizhpharm相关审阅意见，将建立分装后使用期限管理，并与原厂有效期概念区分。

2. **关于分装过程风险（含湿度控制）**  
   现行分装过程控制（SOP、温湿度监控、暴露时限、QA监督、密封检查）及历史偏差/OOS回顾显示，与密封失效、异常吸湿直接相关的过程风险可控。针对聚维酮K30、羧甲淀粉钠供应商提出的“分包装湿度≤40% RH”建议，实验室吸湿性实验表明：在本公司实际分装暴露窗口及45%–65% RH条件下，相关辅料关键质量属性未发生不可接受变化。据此，分装过程可继续维持现行环境湿度控制策略；该结论仅适用于过程风险控制，不延伸为长期贮存效期结论。

3. **关于分装包装贮存风险**  
   部分辅料在分装包装形式下的回顾性近/过效期检验提示，现行分装包装具有一定质量保持能力，但批次与时间点有限，证据强度不足以支持继续沿用原厂有效期。滑石粉、硬脂酸镁尚需通过稳定性研究补齐数据。

4. **关于对制剂产品质量的影响**  
   使用分包装辅料与未分包装辅料生产的西达本胺片，在崩解、溶出、硬度、含量均匀度及稳定性方面对比未见不可接受差异，表明在现行控制下分包装操作未对产品质量造成可识别的不利影响。该结论支持继续采用分包装辅料生产，但不能替代辅料分装后使用期限的建立。

5. **关于后续控制策略**  
   本公司将通过以下措施形成完整闭环：  
   （1）分包装辅料投产前质量控制（聚维酮K30、羧甲淀粉钠）；  
   （2）分包装辅料稳定性研究并批准分装后使用期限；  
   （3）西达本胺片持续稳定性考察。  
   在分装后使用期限正式建立前，不以“沿用供应商出厂有效期”作为放行与库存管理依据。
