## 一、目的与依据

根据变更控制 **CH-2026-052**《CS 片铝铝包装工序包材（聚酰胺铝聚氯乙烯冷冲压成型固体药用复合硬片、药用铝箔）规格变更》及变更控制 **CH-2026-026**（新增 **BM350** 泡罩包装机，用于替换现有铝铝包装设备）：新设备所用包材规格尺寸与现用包材不同，设备厂家需使用新规格包材进行出厂前调试。

新规格包材已于 **【2026 年 ×× 月 ×× 日】** 到货。为在全项放行检验完成前，将**限定数量**的待验包材邮寄至设备厂家用于调试，并规定调试余料由厂家销毁、不得退回合格库，特制定本临时措施。

本文件**不替代**包材质量标准检验与放行，**不批准**待验包材用于本公司任何药品包装或商业生产。

## 二、适用范围与物料状态

1. 仅适用于下表所列包材名称、尺寸、批号及本次外发数量，不得扩大到其他批次或其他用途。
2. 物料部完成到货验收（数量、包装完整性、规格尺寸与订单一致、随货资料齐全）并判定验收合格后，系统及实物标识仍为**待验**。在质量控制部按质量标准完成全项检验并放行前，本批不得作为合格包材发放至生产工序。
3. 本次外发仅豁免“调试用限量包材须等待放行完成后方可出库寄出”的等待要求，**不豁免**留厂部分的请验、全项检验与放行。

## 五、外发与邮寄

1. 生产部或设备项目组填写外发申请，注明关联变更 CH-2026-052、CH-2026-026，用途为“BM350 厂家调试，不用于药品包装”，经质量保证部批准后交物料部执行。
2. 物料部核对：验收合格、状态为待验、批号与尺寸与上表一致、外发数量不超过批准量。从待验区发放，**不得**办理合格品出库。
3. 外发包装上及随货清单均应标识：
   - 待验；
   - 仅供【设备厂家】BM350 设备调试；
   - 禁止用于药品包装；
   - 未使用完部分由厂家销毁，不得作为合格品退回本公司仓库。
4. 物料部办理邮寄或托运，保留运单。随货附：本临时文件复印件、出库/发运清单（品名、尺寸、批号、数量）、签收及销毁要求。
5. 厂家应在收货后 **【2】** 个工作日内书面签收（品名、尺寸、批号、实收数量、破损情况）。实收与实发不符时，物料部立即报告质量保证部，按偏差处理。
6. 如为印刷图文铝箔，外发、运输、使用及销毁按印刷包装材料控制，防止流入市场或其它产品；销毁须不可复原。

## 六、厂家使用与余料销毁

1. 寄出包材仅可用于 BM350 出厂调试/工厂测试，不得用于包装任何药品、食品或第三方产品，不得转借、转让或挪作他用。
2. 调试结束后，**未使用完的包材（含残卷、边角料、试机废片）由设备厂家销毁**，不得退回本公司作为合格或待验物料继续使用。若厂家坚持退货，只可按**待销毁**接收，隔离存放后由本公司销毁，**禁止**再入合格库或待验合格化。
3. 厂家应在调试结束（或确认不再需要该包材）后 **【10】** 个工作日内向本公司提交销毁证明，至少包括：
   - 品名、尺寸、批号；
   - 签收数量、使用数量、销毁数量（及合理损耗说明）；
   - 销毁日期、方式、地点、执行人及见证人；
   - 厂家盖章。
4. 数量关系：签收数量 = 使用数量 + 销毁数量 + 书面说明的损耗。不平衡不得关闭本文件。
5. 质量保证部审核销毁证明并归档于 CH-2026-052、CH-2026-026。

## 七、留厂物料

留厂待验包材继续隔离，按现行程序请验、全项检验，合格后方可用于后续设备确认或产品包装（须另符合 CH-2026-052、CH-2026-026 的批准范围）。外发调试结果**不视为**本批包材放行依据。

## 八、禁止事项

1. 禁止将待验包材发放至口服固体制剂车间用于产品包装、工艺验证包装或留样包装。
2. 禁止以本文件为由免除留厂包材的全项检验与放行。
3. 禁止外发数量超出批准表或将其它批次混入本次邮寄。
4. 禁止接收厂家退回物料并直接按合格品入库。

## 九、生效、失效与关闭

本文件自批准之日起生效。

**不以 BM350 到货为自动失效条件。** 到货仅表示设备物流完成，外发包材的签收、使用、销毁和数量平衡可能尚未关闭。

本文件在质量保证部确认下列事项均完成后关闭并失效：

1. 表列外发数量已寄出且厂家已签收；
2. 销毁证明已收回且数量平衡关闭（或退回待销毁物料已在本公司销毁并记录）；
3. 相关记录已归档至 CH-2026-052、CH-2026-026。

若上述事项长期未关闭，本文件有效期至 **【批准后 90 日】**；到期仍未关闭的，由质量保证部决定延期或转偏差，不得默认失效后继续外发。

关闭后，任何新的外发需求须另行批准，不得沿用本编号。

## 附件：相对 2026 年第 007 号草稿的修改说明（签发时删除）

草稿原逻辑是：验收合格后**无需放行检测**，由**生产部领用**，供供应商制造 BM350 时测试，**设备到货后自动失效**。与现行意图（待验限量邮寄厂家调试、余料厂家销毁）不符，且存在下列合规缺口，已在签发稿中改掉。

| 原稿问题 | 修订 |
|---|---|
| “无需完成放行检测”像整批免检 | 改为：仅限量外发可不等放行；留厂部分仍须全检放行；调试不能当放行依据 |
| 生产部领用，未写邮寄、签收 | 改为物料部从待验区分割、贴签、邮寄；厂家书面签收 |
| 未规定余料去向 | 明确未用完由厂家销毁；禁止退回合格库 |
| 到货自动失效 | 失效改为签收+销毁+数量平衡关闭；到货不自动失效 |
| 未限制用途 | 禁止车间用于任何药品包装；厂家不得转让、不得包装药品 |
| 清单只有名称/尺寸/批号 | 增加：到货量、外发量、留厂量、待验状态、收货厂家 |
| 主送无 QC、无项目组 | 增加质量控制部、工程/设备项目组，避免误放行 |
| “铝塑泡罩”与铝铝变更易混 | 保留 BM350，写明用于替换现有铝铝设备 |

签发前必填：到货日期、批号、到货/外发/留厂数量、厂家全称地址收件人、签收与销毁时限、工程部门名称、批准后有效期日历日。
