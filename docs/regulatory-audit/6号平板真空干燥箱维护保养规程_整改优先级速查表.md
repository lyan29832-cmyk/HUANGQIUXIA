# 6号平板真空干燥箱维护保养规程 — 整改优先级速查表

配合《审核报告》使用。级别：致命 = 不关闭不得批准；严重 = 批准前须关闭；主要 = 首版可列 CAPA 但检查高风险；次要 = 文字与体例。

| 编号 | 级别 | 条款 | 问题一句话 | 关闭动作 |
|------|------|------|------------|----------|
| C-01 | 致命 | 范围 / 记录 | 范围写全车间，记录只对 6 号机 | 锁定设备编号或做台账附件 |
| C-02 | 致命 | 4 / 5 章 | 编制依据、定义写“无” | 补 GMP、SMP、说明书、确认报告 |
| C-03 | 致命 | 6.1 / 6.3.1 | 热水加热 vs 电加热未说明；出现“防爆离心机” | 按 P&ID 改系统名，删离心机 |
| C-04 | 致命 | 全文 | 真空泵及真空管路未列入 | 日常 + 定期补泵、阀、滤器、保压 |
| C-05 | 致命 | 6.2 / 6.2.7 | “日常”实际写成每月一次 | 拆开：每次点检 / 月度 / 半年 / 年 |
| C-06 | 致命 | 7.1 vs 6.2.4 | 先断电才能检查，又要求通电看升温 | 带电点检与断电检修分列 + LOTO |
| S-01 | 严重 | 6.2.3 | 只有“是否正常”，无合格标准 | 回填真空度、温差、保压漏率 |
| S-02 | 严重 | 6.4～6.6 / 7.4 | 无维修后清洁、放行、再确认；操作工可“排除故障” | 写放行步骤；限制操作工维修范围 |
| S-03 | 严重 | 043 / 044 | 两本记录职责重叠 | 改表名与栏目，禁止重复空打钩 |
| M-01 | 主要 | 3 职责 | QA 只监督；无计量、班长、计算机化系统 | 按建议稿 3.1～3.6 补 |
| M-02 | 主要 | 6.1.1 | “污染小故不损坏质量”不成立 | 改为预定用途 + 确认范围 |
| M-03 | 主要 | 6.2.3 表 | 空行合并、液位对象不明、漏急停 / 接地 / 连锁 | 一行一项；液位写循环水 |
| M-04 | 主要 | 6.3 | 半年无泄漏试验；年度几乎不增加深度 | 半年保压 + 连锁；年度确认评估 |
| M-05 | 主要 | 7.3 | 只校真空表和温控仪 | 按仪表台账列全，超期禁用 |
| M-06 | 主要 | 触控屏 | 未当计算机化系统管 | 参数 / 程序变更受控 |
| M-07 | 主要 | 润滑 / 接触件 | 未写食品级润滑和备件规格 | 补附表 3 |
| M-08 | 主要 | 7.4 | 操作要求塞进维护规程 | 退回操作 SOP |
| m-01 | 次要 | 文头 | 无编号版本批准页 | 文件控制 |
| m-02 | 次要 | 用语 | 干燥箱 / 烘箱混用；“静止状态”不专业 | 统一名称；写破空 / 卸压 / 验电 |

**现场必须先看一眼再改字的三项：** ① 加热是电加热热水循环还是其他；② 真空泵型号及有无冷凝回收；③ 是否烘干有机溶剂（决定防爆与冷凝项是否适用）。
