## P2 — 体例、EHS 与加严建议

- 目的补防污染、可追溯、版本正确
- 6.2.1.2 标题改为“外观及包装完整性检查”
- 色标补红色不合格、已取样
- 注意事项：禁混垛、禁已打印退合格库
- EHS：粉碎安全、铝箔划伤、作废件防回流
- 有 WMS 时写第 109 条降级操作
- 切割标签的 100% 电子核对写在包装 SOP，本规程一句引用
- 建议标签库月度盘点；抗肿瘤药印刷件差异升级偏差

## 数量规则备忘（替换 98%）

```
计数类：账存 = 实际确认数量（整箱原包装完整 × 单箱数量 + 抽查/零头清点）
        与送货单差异 → 记录；超批准窄限度 → 拒收或偏差，报 QA
        不得：实际/标识 ≥98% 视为合格

称重类：账存 = 实测净重（检定衡器，去皮）
        不得用 2% 覆盖未到货重量

出库：  按需求量发整包装；实发记入领料凭证
        物料平衡 = 发放 − 使用 − 残损销毁 − 退库，在包装工序完成
        显著差异 → 调查，结论前成品不放行
```

## 状态标识备忘（第 112 条）

| 状态 | 色标（现行惯例） | 可否发放 |
|------|------------------|----------|
| 待验 | 黄 | 否 |
| 已取样 | 在待验基础上加注 | 否 |
| 合格 | 绿 | 是（且在有效期/复验期内） |
| 不合格 | 红 | 否 |

货位卡/系统同时有：名称、代码、企业接收批号、供应商批号、版本、数量、有效期或复验期。
