# 整改优先级速查表（平板真空干燥箱操作规程）

> 配合《平板真空干燥箱操作规程_审核报告.md》。送审稿无文件编号。

## P0 — 不关闭则不能批准

| ID | 问题 | 位置 | 正确方向 |
|----|------|------|----------|
| P0-1 | 写明关机/关屏则干燥电子数据丢失，却用“开到第二天”当控制 | 6.6 | 掉电保持或结束即打印+受控导出；关机丢数据的系统不得当唯一原始记录 |
| P0-2 | 触摸屏自设参数，不绑定批记录/工艺规程 | 6.3 | 参数必须与当批 BPR 一致，第二人复核；操作员不得改配方 |
| P0-3 | 无真空泵、真空设定、泄漏、破真空介质 | 6.3 及全文 | 补泵操作、目标真空、漏气停机、氮/空气破空写死 |
| P0-4 | 编制依据/相关文件/派生记录写“无”，却引用运行记录 | 4、9、10、6.3 | 列 GMP、说明书、确认报告、工艺规程、清洁/维护 SOP；派生记录填 REC-EQ-300-001 |
| P0-5 | 范围不锁设备编号；一楼可能多台 | 2 | 写设备编号/型号/房间；与 6 号维护、清洁 SOP 对齐 |
| P0-6 | 6.1 及示意图空白；检查表大量空行、项与内容错位 | 6.1、6.2、6.3 | 补界面/阀位图，或删空章；每行有检查内容与合格标准 |
| P0-7 | 使用前不确认清洁状态、清场、物料批号 | 6.2～6.3 | 指向清洁 SOP 与状态标识，禁止脏设备装料 |

## P2 — 人因与体系打磨

- 能改则改液位红绿与常规一致，不能改则永久标识
- 阀位开/关一行表；先抽真空检漏再加热
- 防爆区使用笔记本电脑/U 盘做 EHS 评估
- 十天排水改为有依据的停用期限，并写再启用步骤
- 操作 / 清洁 / 维护三份 SOP 同一设备编号互相引用
- 补版本变更历史与批准页
