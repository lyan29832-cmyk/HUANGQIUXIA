## 1. 总体评价

现稿方向正确的部分包括：

- 范围已锁定 **7 号机**，比 6 号干燥箱“范围写全车间、记录写单机”清楚；
- 概述写到制氮置换达标后才进入工作流程，说明现场知道溶剂离心需要惰化；
- 日常有外观、锈蚀、漏油、机盖插销；定期有轴承手盘、密封圈、防松件、皮带、电控、制氮阀门；
- 7.2 写明运转中及未停稳禁止手触转鼓，换滤网须开盖、插安全销、断电；7.6 写制氮检修先泄压；
- 回指 SMP-EQ-100-003，维修与预防性维护分记录。

作为原料药氮气保护平板离心机的维护文件，现稿不合格。核心不是字数少，而是 **高速回转设备的维护动作本身可能制造事故，且无法证明惰化、联锁、分离性能仍处于确认状态**：

1. **6.2.4～6.2.6 把开盖、启转写成“日常保养”**，未要求空鼓、氮置换、开盖联锁、零转速，与 6.1.1、7.2 自相矛盾。
2. **日常与月度再次混编**（6.2 标题日常，6.2.8 每月一次），与 6 号干燥箱同一模板病。
3. **氮气系统只写到“阀门和指示灯”**，氧含量仪、微正压维持、与主机启动联锁整段缺失。
4. **滤布 / 滤网、母液出口、振动、制动、变频器、接地静电几乎不在保养表里**；“全翻壳”机构本身也未出现。
5. 无合格标准、无维修后清洁放行、无重大维修再确认；7.5 再次授权操作工“排除简单故障”。

综合判定：**文件状态 = 不可批准（Critical / Major 未关闭）**。  
与 6 号干燥箱规程对照：两份是同一套空模板换设备名。干燥箱里误写的“防爆离心机”，很像从本系列离心机文件拷过去的残留。建议两份一起改模板，不要各改各的。

## 2. 必须修订项（致命 / 严重）

### 2.1 【致命】编制依据写“无”，定义写“无”

与干燥箱稿相同。离心机另须在依据中明确：

1. 《药品生产质量管理规范》（2010年修订）设备章、校准节；
2. 附录《原料药》第六至十条（润滑剂 / 热媒不得污染产品，清洁防交叉污染）；
3. ICH Q7 第 5 章；
4. **GB 19815-2021《离心机 安全要求》**（防护罩 / 开盖联锁、制动、振动、维护安全）；
5. 〔JB/T 10769 平板式离心机技术条件，如适用〕；
6. SMP-EQ-100-003（注意：本稿写《设备预防性**维护、维修**保养管理规程》，干燥箱稿写《设备预防性**维修、维护**保养管理规程》，同一文件不可能两个名字，先统一受控标题）；
7. 本机说明书、电气 / 气动原理图、氮气 P&ID、IQ/OQ/PQ；
8. 操作规程、清洁规程、校准、偏差、变更、再确认、LOTO、防爆区作业。

定义至少增加：日常点检、预防性维护、重大维修、再确认、产品接触面、零转速、安全销 / 开盖联锁、惰化（氧含量）、安全附件。

---

### 2.2 【致命】6.2.6 日常“开启电源，启动转动”与 6.1.1、7.2 互相否定

| 条款 | 现文 | 冲突 |
|------|------|------|
| 6.1.1 | 制氮置换，腔内气体达到设定值后 **才启动进入工作流程** | 日常启转完全不提氮气和氧含量 |
| 6.2.4 | 打开机盖，转动插销，检查机盖是否固定 | 开盖作业无 LOTO、无零转速确认、无箱内物料状态 |
| 6.2.6 | 盖好后通电 **启动转动**，看异响是否顺畅 | 未规定空鼓、联锁已接通、氮置换完成、无人将手/工具留在鼓内 |
| 7.2 | 未完全停止前禁止接触转鼓；换滤网须插安全销、切断电源 | 日常保养却在“检查机盖”名义下开盖、再启转 |

这是本文件最危险的一条。平板离心机伤人事故的典型路径就是：以为已停转、开盖伸手、或盖未锁死启动。把“启动转动”写进日常保养且无前置条件，等于用规程鼓励违章。

GB 19815 要求防护装置 / 机盖设置联锁：盖未关闭不得启动，盖打开应使设备不能运转。日常点检应验证 **联锁有效**，而不是绕过联锁去“转一下看看”。

**建议拆开：**

1. **使用前点检（不通电或仅上电不启转）**：外观、漏油、基础位移、盖与插销、视镜、急停、氧含量仪在校准期内、氮压正常、滤布完好、出液口畅通。
2. **空载功能检查（有计划、有人监护）**：确认空鼓、无工具、盖关闭锁定、联锁接通、按操作规程完成氮置换且氧含量 ≤〔确认值〕后，才允许点动 / 升至〔点检转速〕，听异响、看振动。不得当作“每月打钩必做的随便转一转”。
3. **开盖检查**：必须零转速（观察 + 等待时间 + 制动确认）、断电 LOTO、插入安全销、腔内无未隔离物料；开盖后禁止点动主机。

6.2.4“打开机盖……检查机盖是否固定住”逻辑也不清：盖已打开时，插销应锁的是 **开位防坠落**，不是运行锁紧。6.2.5“先转插销，看盖是否要用力才能盖上”可能是在查盖变形或销未退出，但未写合格标准。应改为：闭盖前销在退出位，盖靠自重 / 规定操作应能到位，不得用身体压盖强行扣死；到位后锁紧，限位开关动作。

### 2.3 【致命】氮气惰化只写在概述里，保养表不维护“设定值”

6.1.1 把制氮机列为附属设备，并写“达到设定值后启动”。这是溶剂原料药离心的生命线。现稿半年度只查“气动阀门是否开启、指示灯是否显示”，年度只查“电磁阀动作、管路有无泄漏”。

未出现：

| 应有项目 | 为何必须 |
|----------|----------|
| 氧含量分析仪（位号、量程、校准） | “设定值”靠它判定；失准会在富氧下启转 |
| 氧含量联锁：高于〔〕% 禁止启动 / 运行中切断 | 指示灯亮不等于联锁有效，半年须做一次动作试验 |
| 大流量置换 + 小流量微正压维持 | 只置换一次、运行中漏风，氧含量会回升 |
| 氮封压力 / 微正压、超压泄放 | 压力过低等于没惰化；过高可能顶开机盖或损坏密封 |
| 氮气纯度、流量、过滤器、排水 | 制氮机本身要保养（PSA 分子筛、过滤器、储罐排水），不是只看阀 |
| 机盖未关禁止充氮 / 禁止启动 | 与开盖联锁是一套逻辑 |
| 检修泄压后的复压与再惰化 | 7.6 只写泄压，不写恢复 |

没有氧含量仪的校准和联锁试验，6.1.1 的“达到设定值”在文件里是空话。若现场其实用“充氮计时”而没有测氧，须在文件中写明并做风险论证，不能假装有设定值。

### 2.4 【致命】“全翻壳”名实不符，翻壳 / 卸料机构未列入保养

设备名称是 **平板全翻壳离心机**，6.1.1 卸料写成 **“固体物从上部开盖取出”**。行业里：

| 型式 | 卸料方式 | 维护重点 |
|------|----------|----------|
| 上部卸料 / 翻盖 | 开上盖，人工挖料 | 机盖液压撑杆、锁紧、安全销、滤布 |
| 大翻盖 | 液压把大盖翻起 | 液压缸、平衡、限位、防坠落 |
| 全翻壳 | 壳体整体翻开卸料 | **翻壳驱动、锁紧销、翻转限位、防坠落撑杆** |
| 刮刀下卸料 | 刮刀刮料、底部出料 | 刮刀间隙、刮刀联锁、下出料阀 |
| 翻袋 | 滤袋翻转卸料 | 袋、翻转机构 |

现稿保养项只有“机盖、插销”，没有翻壳油缸 / 锁紧 / 限位，也没有刮刀。两种可能：

1. 实际是上部开盖人工卸料，名称叫“全翻壳”不准确，应改名并按翻盖机维护；
2. 确实有全翻壳机构，则现稿 **漏掉了这台机器区别于普通平板机的核心机构**，翻转中坠落或未锁死启转都是恶性事故。

必须对照铭牌、说明书、现场照片改系统组成，不能在名称和卸料描述上各写各的。

### 2.5 【致命】日常写成每月一次；041 / 042 职责不清

| 条款 | 现文 | 问题 |
|------|------|------|
| 6.2 标题 | 日常保养 | 日常 = 每次使用 |
| 6.2.7 | 操作人员完成 | 可以 |
| 6.2.8 | **每月一次**，登记“日常”记录 042 | 与干燥箱 6.2.7 同一句式 |
| 6.6 | 维护保养另填 041 | 月度算日常还是预防性 |

离心机班前不做点检（基础是否位移、漏油、盖锁、氮压、急停），只靠每月转一转，不符合高速设备安全管理，也不符合 GMP 第八十条的可执行预防性维护。

6.2.9 / 6.2.10 允许提前或生产期间同步保养：同步保养若包含开盖、加脂、动皮带，会污染在制批次。须写：生产期间只允许做非产品接触、不停机外观项；开盖、润滑、皮带、氮气管必须停产、卸料、清洁隔离后做。只允许提前，不允许无故延后。

建议层级：

| 层级 | 频次 | 责任 | 记录 |
|------|------|------|------|
| 使用前 / 使用中点检 | 每次 | 操作 | 042 点检栏或批记录 + 运行日志 |
| 月度保养 | 每月 | 操作为主，维修巡检 | 042（建议改名为月度检查记录） |
| 半年度 / 年度 PM | 6 / 12 个月 | 维修为主 | 041 |

### 2.6 【严重】检查无标准、无不合格路径；试机正常即可开机

全文件没有一条数值标准：氧含量设定值、振动烈度、转速、皮带挠度、轴承温升、氮压、盖限位是否动作，全部靠“正常 / 有无异常”。

7.3 / 7.5：“必要时拆洗维护”“简单故障及时排除”“试机正常后开机”。缺：

- 待修 / 禁用标识；
- 偏差与批次影响评估（轴承异响、氮系统失效、滤布破损都可能影响已离心物料）；
- 维修后按清洁规程清洁产品接触面（转鼓、壳体、盖内侧、出液管）；
- 重大维修再确认（GMP 第八十一条）：换转鼓 / 主轴承、改变频器参数、改氧含量或开盖联锁逻辑、动平衡、改氮气回路；
- 谁有权放行。

操作工可做的限度：停机、按规程等待停稳、急停、关阀、报告。手盘转鼓、加脂、调皮带、拆氮气管、改接线，不是“简单故障”。

---

### 2.7 【严重】产品接触件——滤网 / 滤布几乎只在注意事项里出现

7.2 提到“更换滤网”，正文保养项目完全没有：

- 滤布 / 滤袋规格、安装方向、压条 / 涨圈是否到位；
- 破损、结晶板结、网孔堵塞；
- 换滤布后的清洁与安装复核；
- 滤布作为产品接触备件的批准规格（附录《原料药》接触面与交叉污染）。

滤布破损会穿滤、金属丝落入下一批、母液浑浊。这是原料药离心机维护的第一产品风险项，不能只写在注意事项。

母液出液口、视镜、进料管、洗涤管（如有）同样未列入。

## 3. 主要缺陷

### 3.1 设备概述不完整，且有科学漏洞

6.1.1 把组成写成“平板、电机、轴承座、外壳、离心转鼓、减振装置和电控系统、附属设备制氮机”，缺：

- 设备编号、型号、厂家、最高转速、防爆标志；
- 滤布、出液系统、机盖锁紧与安全销、〔液压翻盖 / 翻壳〕、变频器、制动、振动开关、氧含量仪、氮气管路；
- 产品接触材质。

“液料经过变频调速后在转鼓内按照工艺要求的速度分离”——变频调速的是 **转鼓转速**，不是液料先变频再进鼓，语序不准确。

“运转时减振装置消除震动”——减振装置只能衰减，不能保证消除；振动超限应停机，概述写成必然消除会误导点检人员忽略振动。

“固体物从上部开盖取出”须与“全翻壳”名称对齐（见 2.4）。

概述不要写保证性结论，应写预定用途：在确认的转速、装载量、氮封氧含量范围内，用于〔工序 / 物料〕的固液分离。

---

### 3.2 职责不完整

| 角色 | 现稿 | 应补 |
|------|------|------|
| 设备工程部负责人 + QA | 监督实施 | QA 还须批准文件、复核记录、偏差 / 再确认、否决带病运行 |
| 设备工程部 + 操作人员 | 一句“执行” | 维修做 PM 和维修；操作做点检和允许范围内的月度项 |
| 班长 | 无 | 提前保养审批、生产期间禁止开盖保养 |
| 计量 | 无 | 氧含量仪、振动表、转速表、压力表送校 |
| 无人负责 | — | 变频器参数备份、联锁逻辑变更 |

3.1 写“设备工程部**负责人**和 QA 监督”，3.2 写整个设备工程部执行，与干燥箱稿略有不同，仍未把维修工与操作工拆开。6.3.3 已写“维修为主、操作为辅”，职责章应与之一致。

### 3.3 半年度 / 年度过薄，关键安全功能未试验

6.3.1 有价值的条目：手盘听轴承、密封圈、防松件、皮带、电控保护开关、制氮阀。但仍缺：

| 项目 | 意见 |
|------|------|
| 手盘转鼓加脂 | 必须空鼓、断电、安全销；润滑脂牌号 / 食品级或相当；“视情况”改为周期 + 判据（异响、温升、运行小时） |
| 皮带裂痕松紧 | 补 quant：挠度 / 张力规定；油污、轮槽对齐 |
| 保护开关 | 须列出：急停、开盖限位、过振动、电机过热、〔料满〕，并做动作试验 |
| 视镜灯 | 可保留 |
| 制氮阀 | 升格为氧含量 + 压力 + 联锁试验 |
| **振动** | 概述有减振装置，保养不测振动值，半年至少测一次并与确认 / 出厂值比 |
| **制动** | 未写；高速机停稳时间是安全项 |
| **开盖联锁** | 未做“开盖不能启动、运行中开盖应停”的试验（试验方法须安全，不得真的在高速时掀盖） |
| **转速** | 变频器显示与实测（手持转速表）比对 |
| **接地 / 等电位** | 溶剂 + 过滤属于静电高风险，年度只写“电机接地”不够，壳体、管道跨接也要查 |
| **转鼓本体** | 裂纹、腐蚀、滤孔变形、动平衡异常征兆（振动恶化） |
| **基础 / 减振器** | 日常只写位置移动，定期应查减振器老化、地脚螺栓力矩 |
| **翻壳 / 翻盖液压**（如有） | 油位、泄漏、限位、机械锁 |

6.3.2 编号从“7.”起，显然是从 6.3.1 的 1～6 顺手编下去，文件控制不严谨。年度内容 = 半年 + 电气端子 + 电磁阀泄漏，深度不够。年度应增加：绝缘 / 接地测量、变频器参数与确认版本核对、制氮机过滤器 / 〔分子筛〕保养、轴承评估、联锁全项试验、确认状态评估（是否需要动平衡或转速 / 振动复测）。

### 3.4 安全注意事项与维护规程混编，且自我打架

| 条款 | 问题 |
|------|------|
| 7.1 专人操作 | 属操作规程 / 岗位资质，不是维护条款 |
| 7.2 | 方向正确；应补：零转速确认方法、LOTO、腔内溶剂蒸气 / 氮气窒息（探身入鼓视为有限空间作业） |
| 7.3 停机后拆洗 | 谁拆、拆到哪一步、清洁规程号；操作工拆轴承座不可接受 |
| 7.4 旋转方向 | 好；应写核对铭牌箭头、首次送电或倒相后必须点动确认，反转会松转鼓螺母、毁滤布 |
| 7.5 不得离岗、简单故障排除 | 与干燥箱 7.4 同病；劳动组织应退回操作 SOP |

7.2 写换滤网须切断电源，6.2.6 写日常启动转动，两章不能同时成立。

### 3.5 校准与计算机化系统

未列出关键仪表：

- 氧含量分析仪（最高优先级）；
- 腔体 / 氮封压力表或变送器；

### 3.6 润滑、漏油与产品保护

6.2.3“检查是否有漏油”未写部位：主轴承座、电机、〔液压站〕、减速机（如有）。轴承座漏脂进入转鼓是原料药不可接受污染（GMP 第七十七条，附录《原料药》第六条）。应写：

- 漏油即停用评估；
- 润滑脂批准牌号、加注点、加注量、严禁加到产品接触面；
- 开盖保养时箱内不得有待隔离物料；工具、销、螺钉计数。

## 6. 建议关闭顺序

1. **现场核对铭牌、说明书、氮气 P&ID、联锁清单**：卸料型式、有无翻壳液压、氧含量仪是否存在、滤布规格、防爆标志。  
2. 删改 6.2.4～6.2.6：禁止把无条件启转写成日常保养。  
3. 补氧含量、开盖联锁、振动、制动、滤布、出液口。  
4. 拆分每次点检 / 月度 / 半年 / 年度；改 041、042 栏目。  
5. 补合格标准、LOTO、清洁放行、再确认、润滑级别。  
6. 7.1 / 7.5 操作要求退回操作 SOP。  
7. 与 6 号干燥箱规程统一模板和 SMP-EQ-100-003 标题。  
8. QA 组织一次纸面演练（按真实开停机顺序勾空表）后再批准。
