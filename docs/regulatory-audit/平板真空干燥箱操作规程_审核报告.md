## 1. 总体评价

现稿有用的部分：

- 把开机顺序、补水、拆烘架、打印、U 盘拷贝写成步骤，比只有“按说明书操作”可检查；
- 6.3 破真空阀门不可开太大、7.2 先手动出纸再撕、7.4 报警须复位、7.5 探针须接触加热板，说明现场踩过坑；
- 7.1 长期停用排水、8 章烫伤/劳保/带电清洗，方向对。

作为原料药真空干燥操作规程，现稿不合格。核心不是字数少，而是 **写的不像这台设备的“生产操作”**：

1. **真空干燥的核心（真空泵、真空设定、泄漏、破真空介质）几乎缺席**，只剩屏上一个“抽真空”按钮。
2. **工艺参数由操作员在触摸屏自设**，未强制与批生产记录 / 工艺规程一致——这是批间差异和超温的最大来源。
3. **6.6 写明：控制面板关掉，干燥电子数据会丢。** 这不是注意事项，是数据完整性不合格；关机丢数据的系统不能当 GMP 电子记录源。
4. 与 6 号机**维护**规程同一套空模板：编制依据 / 定义 / 相关文件 / 派生记录全部写“无”，检查表大量空单元格，6.1 触摸屏介绍和多数“示意图”为空白。空白规程在检查中等于未培训、不可执行。

综合判定：**文件状态 = 不可批准（Critical / Major 未关闭）**。  
建议与维护规程、清洁规程（现场清洁验证曾引用 SOP-EQ-212-025）三份一起改，不要操作写一楼、维护写 6 号、清洁另编号，三套对不上。

## 2. 必须修订项（致命 / 严重）

### 2.1 【致命】关机丢电子数据（6.6）

现文：

> 干燥工序结束后，应保持控制面板开启至第二天收料完，否则会导致干燥产生的电子数据丢失。

这等于承认：温度/真空/时间曲线只存在易失存储或打印机缓冲区里，**断电或关机 = 批记录电子部分灭失**。不符合《药品记录与数据管理要求（试行）》对原始数据保存、备份、防止丢失的要求，也不符合 ALCOA+ 的 Enduring。

风险场景（均会发生）：夜班误关总电、跳闸、节假日 7.1 排水时顺便关电、打印机卡纸以为“反正有电子的”、第二天收料前有人关屏。

**必须改的不是把这句话写得更醒目，而是系统或规程保证数据不依赖“人不要关机”：**

1. 每次干燥结束（或每班）**自动**把曲线写入不可改存储（设备存储器 / 工控机 / 服务器），关机不丢；
2. 打印记录为同步副本，打印失败须有电子可恢复，不能互为唯一；
3. UPS 或停电策略：停电后数据已刷盘；
4. 在改造完成前，过渡措施只能是：**停机前强制导出 + 打印签字附批记录**，并开偏差/变更说明该数据风险；不能把“保持开机到第二天”当成控制措施长期用。

“数据为 PDF、不可更改”也不成立。普通 PDF 可改；没有哈希、权限和审计追踪，U 盘拷贝只能当查阅件，原始记录仍须在受控系统或已签字的打印件上。

### 2.2 【致命】工艺参数允许在屏上自设，未绑定批记录 / 工艺规程

6.3“设置参数”：点击项目 → 输入 → 保存，**未写参数从哪来、谁有权改、改了谁复核**。

真空干燥的温度、真空度、升温/恒温时间、抽真空时序是**工艺规程和批生产记录**的内容，不是设备操作员现场发挥。GMP 要求生产按批准工艺；操作 SOP 只解决“怎么在这台机器上把批准参数执行出来”。

现稿后果：

- 甲班 60 ℃、乙班 70 ℃，都能说“按 SOP 设了参数”；
- 管理员口令共用时，历史批次无法证明当时设定值；
- 产品信息“只支持字母+数字”——中文品名、内部物料代码怎么录，不写就会乱编或空着。

**建议改为：**

> 温度、真空度、各阶段时间等过程参数**必须与当批批生产记录及现行工艺规程一致**，不得擅自更改。触摸屏仅允许录入批记录已批准的数值；录入后第二人复核，与批记录不一致不得启动。配方/权限由〔工艺员/系统管理员〕受控下发，操作账号不得改配方。

账号密码条款须补：一人一号、禁止共享、权限分操作/管理员、密码定期更换、审计追踪谁改了设定值。无审计追踪则打印记录必须含设定值与实际值，并签字。

---

### 2.3 【致命】真空系统未写入操作步骤

平板**真空**干燥箱没有真空泵、真空阀、真空表合格标准、泄漏判断，就不能叫本设备的操作规程。现稿：

| 应有内容 | 现稿 |
|----------|------|
| 真空泵启动/停止顺序、油位或水环水位、气镇、冷凝器 | 无（只有屏上“抽真空”） |
| 空载/带载应达到的真空度及时限 | 无 |
| 抽真空与加热的先后（先抽后热 / 边抽边热，以工艺为准） | 无，只写“点抽真空再点启动，30 s 后加热和循环泵运行” |
| 漏气判断（真空抽不上去、保压掉得快） | 无 |
| 破真空介质（空气 / 氮气）及过滤 | 只写手动开阀、勿开太大 |
| 真空泵与箱体的阀位（防泵油返箱） | 无 |

**破真空介质必须写死。** 热物料放空气：氧化、吸湿、粉尘扬起；含溶剂时还有爆炸性混合气体风险。许多原料药规定**氮气破真空**至微正压再开门。现稿未提氮气，现场若其实用氮，文件与操作两张皮；若用空气，须有质量评估。

6.3“真空将至 0 再取样”——真空表回零后箱内相对湿度会迅速回升，LOD 取样窗口、开门次数、样品密闭应在规程或批记录里规定，并引用干燥失重方法，不能只写“取样测干燥失重”。不合格是复抽、延长还是报偏差，现稿没有。

---

### 2.4 【致命】温度探头放在加热板上，干燥终点只靠时间

6.3：将温度探头放置在加热板上。7.5：L 型软性温度计探针必须与加热平板接触。

这样测的是**板温/热媒温度**，不是物料温度。真空干燥中物料温度常明显低于板温，溶剂汽化还会吸热。把探头贴在加热板上：

- 屏上 60 ℃ 不代表物料到了 60 ℃，也不代表已干；
- 探头离开物料后，超温保护可能保不住物料；
- 与“到达预设时间 → 破真空 → 测 LOD”拼在一起，过程控制变成“定时再抽检”。

更优做法（按确认报告选，不要口头改）：

1. 板温控制加热，**料温或模拟料温**作记录/联锁（探头插入物料层或规定位置的测温块）；
2. 终点以工艺规定为准：时间 **且** 真空度稳定 **且** LOD 合格，而不是只到时间；
3. 若确认报告就是“板温 + 时间 + LOD”，文件须写明这是已确认策略，并规定探头贴板的固定点（哪一块板、如何固定），防止每班贴的位置不同。

现稿 7.5 与 6.3 只强调“必须接触加热板”，不强调位置可重复，检查时无法复现。

### 2.5 【致命】范围未锁设备编号；编制依据 / 相关文件 / 派生记录写“无”

| 位置 | 现文 | 问题 |
|------|------|------|
| 2 范围 | 一楼干燥间平板真空干燥箱 | 未写设备编号、型号。一楼若不止一台，账号、配方、运行记录会串机 |
| 4 编制依据 | 无 | 操作规程不可能没有上位文件 |
| 9 派生记录 | 无 | 6.3 已要求填 REC-EQ-300-001 |
| 10 相关文件 | 无 | 工艺规程、批记录、清洁、维护、计量、数据备份、偏差全部失联 |
| 11 附件 | 无 | 6.1～6.7 需要的界面图、阀位图全部空着 |
| 12 版本历史 | 空 | 无法追溯修订 |

第 9、10 章写“无”与正文自相矛盾，检查员会问：运行记录算不算派生记录？不算则 6.3 引用非法。

编制依据至少应有：GMP 设备与生产操作条款；本机说明书 / P&ID；IQ/OQ/PQ；现行工艺规程与批记录模板；清洁 SOP；维护 SOP；计量规程；计算机化系统 / 数据管理规定。

相关文件至少勾上：对应工艺规程、REC-EQ-300-001、清洁 SOP、维护 SOP、干燥失重检验操作、偏差/变更。派生记录改为 REC-EQ-300-001，并说明打印曲线、U 盘导出文件、LOD 结果附于批记录。

目的“规范员工操作，避免因员工操作失误。”句子不完整（避免失误导致什么？），且目的不应只写防呆。建议：

> 规范本机使用前检查、启动、干燥、破真空、结束及数据打印/导出，确保按批准工艺运行，防止混批、交叉污染、设备损坏及数据丢失。

### 2.6 【严重】使用前检查表不可执行，且与维护点检重复却无标准

6.2.1～6.2.6 多数行“检查内容”为空，靠合并单元格意会。6.2.3 检查项是密封条，内容却写“箱体无锈迹”——项与内容错位。6.2.6 加热平板与烘盘写在同一格。

无合格标准、无不合格停用路径，与维护规程同一病。操作前至少要能判定：

- 设备状态标识为清洁合格 / 完好，上一批清场完成（**现稿完全不提清场、清洁状态、物料平衡**）；
- 仪表在校准期内（温度、真空），列出位号；
- 门封完好可抽真空；
- 加热水位在规定区间，循环无泄漏；
- 真空泵可启动（油位等）；
- 烘盘完好、数量与批记录一致，无锈无上批残留。

“避免使用过程中出现故障”不是检查目的。检查目的是：**确认本机处于已确认且可投产状态**。通电升温作为班前必做，会空烧、耗时，且与“有物料才按工艺升温”冲突；功能检查应规定空载还是带载、由谁做、记在运行记录哪一栏。

热水循环泵、加热板“开启后无泄漏”是运行中监控，不宜全放在“操作前”一次看完。应分：操作前目视 + 启动后规定时间内再确认泄漏。

### 2.7 【严重】补水逻辑与红绿指示易导致干烧或溢水（6.5）

现文：红色 = 正常，绿色 = 缺水（与普遍“绿通红停”相反）；缺水无法启动；补饮用水至红；点启动后又变绿，再补，直到启动后不报警；报警须进菜单复位。

风险：

1. **颜色反直觉**，夜班、新员工极易补反或强行复位后干烧加热管；
2. “启动后变绿再补”说明液位计可能在循环回路上，泵一开液位假缺——规程把现象写出来了，但没有上限、没有“禁止在加热器已干烧状态下补冷水”、没有溢流；
3. 补水介质写**饮用水**。夹套/平板热水应规定水质（纯化水或设备确认用水），减少结垢、腐蚀、微生物。更关键：平板或管路泄漏时热媒可能进物料（原料药附录：加热介质不得污染产品）。须有泄漏进箱的应急（停热、不放行本批、偏差），现稿没有；
4. 有报警仍“点启动”的写法，像在教人绕过联锁。应写：先消除缺水原因并复位，水位正常才允许启动；禁止屏蔽低液位。

7.1 十天无生产排水：十天无依据；排尽后首次再补水、排气、检漏、是否再确认空载升温，均未写。与 6.6“必须开机到第二天”在节假日会打架。

---

### 2.8 【严重】计算机化系统与 U 盘拷贝不受控（6.3 / 6.6 / 6.7 / 7.3）

- 登录只写“输入账号密码”，无权限、无禁止共享、无审计追踪；
- 两种导出（读卡器 / U 盘）未规定**主归档是哪一种**、谁导出、导出后原机是否还保留、U 盘专机专用如何发放回收、病毒扫描；
- 打开防爆箱用移动电脑：防爆区带入非防爆电脑/U 盘的 EHS 与数据流未评；
- 打印机自动打、手动出空白纸：空白纸与批记录如何区分、打印中断怎么补打、打印件是否签字附批记录；
- 7.3“存储器专用”正确，但未落实到编号台账。

更优：明确 **批记录以签字的打印曲线 + 批生产记录为准**，电子导出为备份；或相反，以受控服务器为准、打印为副本——必须选定一个原件，不能两个都当原件又都不备份。

## 3. 主要缺陷（可执行性与质量）

### 3.1 6.1 触摸屏介绍、各表“示意图”均为空

没有界面截图的“点击主菜单→参数设置”无法培训、无法检查。空白栏在正式文件里应删掉或补图，不要留“有章节无内容”。阀位、排污、拖车拆架更需要照片或简图，现稿全是“/”。

### 3.2 装料与探头（6.3）缺少工艺约束

“产品均匀分装在烘盘中”没有：单盘装量/厚度上限、盘数、物料代码与批号标识、是否允许不同批次同箱（通常不允许）、烘盘朝向、禁止堆得挡住真空通道。关箱门锁紧无确认顺序（先门后真空）。取出烘盘再装——脏盘、混盘、盘与批记录数量不符均未控。

### 3.3 烘架拆卸（6.4）不该无边界地写进每次操作

排水、拆进出水、拖车拉烘架，属于**清洁、换品种或维修**，不是每次干燥的标准路径。现稿未写：何时必须拆、热水是否已降温卸压、有无残真空、重装后如何检漏再投产、两人对拖的指挥。未降温拆热水接头有烫伤和喷水进箱风险。建议：生产操作只保留“需要拆架时见清洁/维护规程”，或本节加前置条件（已破真空、已降温至〔〕℃、已断电、水已排、状态标识）。

### 3.4 清场、状态标识、物料平衡整段没有

关键设备操作 SOP 至少应指向：使用前确认清洁合格证、设备状态“待用/运行/待清洁”、物料品名批号与指令一致、干燥后收料称重与批记录。现稿从检查直接跳到放产品，检查员会问上批残留谁保证没有。

### 3.5 异常处理只有“报警要复位”

缺：抽真空失败、泄漏、超温、循环泵泄漏进箱、停电、打印中断、LOD 不合格、探头脱落、液位反复报警。每条应有：停哪一步、物料怎么处置、谁决定复开、是否偏差。7.4 只说不解报警不能启动，没说乱复位的禁止。

### 3.6 职责不完整

现场 QA 监督、生产执行——缺车间主任/班长复核参数、维修处理泵和泄漏、QC 做 LOD、计量管仪表、系统管理员管账号。现场 QA 不能写成唯一“负责本规程实施”的人。

### 3.7 EHS 偏少

有烫伤、劳护、带电清洗、搬抬。缺：视镜承压、残真空开门、热水带压拆管、防爆区内非防爆电脑、若氮气破真空的窒息、粉尘、溶剂真空泵排气。8.4“避免使用腰部力量”可保留，但拖车拉烘架才是主要肌肉骨骼风险，应写在 6.4。

## 4. 更优做法（非否决，建议一并改）

1. **阀位检查表**：抽真空前真空阀、破空阀、排污阀、补水阀的开/关状态列成一行表，比长叙述更防呆。
2. **先抽真空后判断泄漏，再加热**：空载或微开真空看能否到确认真空度，漏气不加热，减少湿料长时间受热。
3. **HMI 红绿与现场一致则改屏，不一致则改灯**：长期用“红=正常”是人因事故源，能改尽改，不能改则在屏侧做永久标识，且班前点检读一次。
4. **打印策略**：恒温阶段按确认频率打点即可；升温段过密浪费、过疏看不出超调。与确认报告曲线采样间隔对齐。
5. **U 盘**：只读策略、一次一盘、拷贝后填写导出记录（时间、文件名、批号、操作人），原文件留设备。
6. **目的/范围**按一机一规程；同型号多台用附件台账，参数和记录分机。

## 5. 建议替换的关键表述（可直接贴回规程）

**6.3 设置参数（替换原“输入参数→保存成功”）：**

> 按当批批生产记录填写温度、真空度及各阶段时间，第二人与工艺规程核对后保存。任何修改须经〔授权人〕批准并记偏差/备注。禁止使用上一批残留配方不经核对直接启动。

**6.3 破真空（补一句介质和阀）：**

> 干燥结束：停加热 → 关真空泵隔离阀 → 按工艺用〔氮气/空气〕缓慢破真空，阀门开度以物料不被吹起为准，至真空表〔0 / 微正压〕→ 再开门取样。禁止在高真空下猛开破空阀。

**6.6（替换“保持开机否则数据丢失”）：**

> 干燥结束立即打印过程记录并导出至专用存储器，操作人与复核人在打印件签字，附批记录。确认导出成功前不得关闭控制电源。电子数据须在关机后仍可调取；若本机暂不具备掉电保持，关闭电源前的导出与打印列为强制步骤，并按变更升级存储。

**6.5 补水（补禁令）：**

> 低液位报警时禁止强行启动。查明泄漏或蒸发原因，按〔规定水质〕补至正常液位并排气后复位报警，再启动循环。禁止拆除或屏蔽液位联锁。发现加热板或箱内进水，立即停机，本批不得按正常放行，报偏差。

## 6. 审核结论（再述）

现稿不能批准。优先关闭四件事再谈排版和附图：

1. **数据**：禁止“关机即丢”；打印/导出原件化；  
2. **参数**：屏上数值 = 批记录 = 工艺规程；  
3. **真空**：泵、设定、泄漏、破真空介质写进步骤；  
4. **文件**：锁设备编号，编制依据和相关文件不再写“无”，检查表补标准并补界面图。

其余（探头位置、饮用水热媒、红绿反色、拆架边界、清场状态）按严重项在同一修订版处理。
