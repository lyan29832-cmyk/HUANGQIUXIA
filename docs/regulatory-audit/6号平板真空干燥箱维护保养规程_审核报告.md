## 1. 总体评价

现稿方向正确的部分包括：

- 把维护保养从“故障才修”写成书面规程，符合 GMP 第八十条“应当制定设备的预防性维护计划和操作规程”的形式要求；
- 日常点检覆盖了触控屏、密封条、箱门、视镜、循环泵、加热平板、烘盘等可见部件；
- 区分了半年度 / 年度定期保养，并回指公司级 SMP-EQ-100-003；
- 规定节假日、生产期间可提前保养，避免“过期未做”；
- 维修走 REC-EQ-100-029，与预防性维护记录分开，框架合理。

但作为原料药关键干燥设备的维护文件，现稿不合格，核心问题不是“写得不够漂亮”，而是 **写的设备不像这台设备，做的动作也无法证明设备仍处于确认状态**：

1. **系统识别错误或未闭合**：概述写“热水加热”，定期保养写“电加热系统”，又突然出现“防爆离心机”；真空泵、真空管路、放空阀、冷凝器整段缺席。
2. **日常与定期、点检与保养混编**：6.2 标题是“日常”，6.2.7 却规定“每月一次”，记录还叫“日常维护保养检查记录”。检查员会直接问：班前要不要做？月度漏做算偏差吗？
3. **不可执行**：检查表大量空行靠合并理解；无判定标准（真空度多少算正常、升温多少算正常）；无不合格处置。
4. **安全与操作自相矛盾**：7.1 要求“必须先切断电源方可检查”，6.2.4 / 6.2.5 又要求通电看温度和加热。
5. **GMP 生命周期缺口**：润滑剂级别、产品接触件更换、维修后清洁放行、重大维修再确认、计算机化系统（触控屏）维护、关键仪表校准清单均未落地。

综合判定：**文件状态 = 不可批准（Critical / Major 未关闭）**。

## 2. 必须修订项（致命 / 严重）

### 2.1 【致命】设备对象与范围未锁定，记录只指向 6 号机

| 位置 | 现文 | 问题 |
|------|------|------|
| 2 范围 | “适用于原料药车间平板真空干燥箱” | 未写设备编号、型号、安装位置、是否覆盖同型号其他机台 |
| 6.2.7 / 6.5 | REC-EQ-430-044、REC-EQ-430-043 均写 **《6号平板真空干燥箱……》** | 范围是“车间该类设备”，记录却是单机。一机一规程还是一类一规程，必须二选一 |

**风险：** 其他编号干燥箱若套用本规程，记录编号、备件、确认范围全部错位；6 号机若有专用确认报告，范围写“全车间”会把确认边界冲掉。

**建议：** 范围改为“仅适用于原料药车间 **6 号平板真空干燥箱**（设备编号〔EQ-×××〕，型号〔〕，安装房间〔〕）”。若同型号多台共用正文，用附件列出设备台账，记录一机一表。

### 2.2 【致命】编制依据写“无”，定义写“无”

维护保养 SOP 不是经验汇编。GMP 第七十二条要求建立维护和维修操作规程；第八十条要求预防性维护计划；附录《原料药》第六条约束润滑剂 / 加热介质不得污染产品。现稿第 4、5 章写“无”，等于宣称本规程没有上位法、没有术语边界。

至少应列出：

1. 《药品生产质量管理规范》（2010年修订）设备章及校准节；
2. 附录《原料药》设备与清洁相关条款；
3. SMP-EQ-100-003《设备预防性维修、维护保养管理规程》；
4. 本机使用说明书、P&ID、IQ/OQ/PQ 或再确认报告；
5. 计量器具校准管理规程；
6. 本机操作规程、清洁规程、偏差 / 变更 / 再确认相关 SMP。

定义至少应有：日常点检、预防性维护、重大维修、再确认、产品接触面、安全附件、锁定挂牌（如企业已实施）。

---

### 2.3 【致命】加热方式与“防爆离心机”自相矛盾，真空系统整段缺失

平板真空干燥箱的典型系统是：

| 系统 | 典型组成 | 现稿 |
|------|----------|------|
| 加热 | 加热平板 + 热水 / 蒸汽 / 导热油循环，或电加热热水后再循环 | 6.1.1 写热水；6.3.1.1 写电加热；6.2.3 有循环泵、液位、加热平板 |
| 真空 | **真空泵**、真空阀、真空管、真空表 / 变送器、放空阀；溶剂物料常有冷凝回收 | **全文未出现真空泵** |
| 传动 / 流体 | 循环泵（热水），不是离心机 | 6.3.1.3 写 **“防爆离心机”** |
| 箱体密封 | 门封、视镜、紧固件 | 有，但与箱体检查项粘连 |

**两点必须当场核实，不能在文件里含糊过去：**

1. **“防爆离心机”极大概率是笔误或从离心机 SOP 拷贝残留。** 真空干燥箱不转鼓、不分离固液。更可能是 **防爆离心泵**（热水循环）或误把真空泵写成离心机。在未核对铭牌前，该条一旦按字面执行，维修人员会去找一台不存在的设备，或漏检真正的泵。
2. **真空泵是这台设备的核心动力，不是可选项。** 没有真空泵点检（油位 / 油质或水环水位、异响、极限真空、过滤器、气镇、防返油），所谓“真空干燥箱维护”名不副实。溶剂工况下，泵油乳化和冷凝器堵塞会直接把溶剂或油雾带回箱体，污染原料药。

6.1.1 与 6.3.1.1 可以并存——常见架构是“电加热热水 + 循环泵 + 加热平板”——但现稿从未说明。维护人员无法判断“电加热系统”“加热部件”“加热平板”是同一对象还是三套系统。

**建议修订：** 在 6.1 增加“系统组成”和一张以本机 P&ID 为准的示意图说明；删除或改正“防爆离心机”；日常 / 定期表单独立列出真空系统。

### 2.4 【致命】6.2 把“日常点检”写成“每月一次”，记录与行为对不上

| 条款 | 现文 | 冲突 |
|------|------|------|
| 6.2 标题 | 日常维护保养 | 日常 = 班前 / 班中 / 使用日 |
| 6.2.6 | 由操作人员完成 | 可以 |
| 6.2.7 | **每月维护保养一次**，登记日常检查记录 | 月度保养被叫作日常 |
| 6.5 | 另填 REC-EQ-430-043 预防性维护记录 | 月度算日常还是预防性，两本账 |

GMP 检查常见问法是：

- 今天开工前做了哪些检查？记录在哪？
- 月度漏做如何偏差调查？
- 043 和 044 各记什么，会不会同一事项记两次或两次都不记？

现稿无法回答。6.2.1～6.2.5 从内容看更像 **使用前点检**（外观、通电、升温），却被 6.2.7 收成每月一次。结果通常是：操作工既不班前记，月度又只在表上打钩，设备带病运行。

**建议：** 明确三级：

| 层级 | 频次 | 责任 | 记录 |
|------|------|------|------|
| 使用前 / 使用中点检 | 每次使用 | 操作人员 | 点检记录或批生产记录相应栏 + 设备运行日志 |
| 月度保养 | 每月 1 次 | 操作人员为主，维修巡检 | REC-EQ-430-044（建议改名为月度检查记录，勿再叫“日常”） |
| 半年度 / 年度预防性维护 | 6 个月 / 12 个月 | 维修为主，操作为辅 | REC-EQ-430-043 |

6.2.8 / 6.2.9 允许提前保养可以保留，但须写：**只允许提前，不允许延后；提前须在记录注明原因；生产期间同步保养不得影响在制批次，并避免打开产品接触面。**

### 2.5 【致命】7.1 与 6.2.4 / 6.2.5 互相否定

- 7.1：“必须先切断电源，使箱体处于静止状态，方可进行检查或维修。”
- 6.2.4 / 6.2.5：开启电源观察温度显示、开启加热观察加热系统。

按 7.1 字面，通电点检全部违规；按 6.2 执行，7.1 成空文。审计时这是典型的“文件自己打自己”。

**建议拆成两类作业：**

1. **带电功能检查**：点检显示、升温、循环泵、真空泵运转；规定 PPE、一人操作一人监护（如需要）、超温 / 异响立即停机。
2. **断电检修**：打开电气柜、更换密封条以外的电气 / 管路作业、进入箱体，执行停电、验电、锁定挂牌（LOTO），热水系统先降温卸压，真空系统先破空。

“箱体处于静止状态”表述不专业。真空箱停电阻后仍可能高温、残真空、残压热水，静止 ≠ 安全。

### 2.6 【严重】检查有动作、无标准、无不合格路径

6.2.3 全表只有“是否正常 / 是否完好”。原料药干燥的关键参数至少应能回答：

| 项目 | 现稿 | 应有的合格标准（数值须按确认报告回填，下表为结构示例） |
|------|------|------|
| 真空度 | 无 | 空载〔时间内〕达到〔-0.09 MPa 或确认值〕；保压〔△P/时间〕不超过确认漏率 |
| 温度显示 | “有无异常” | 显示与设定偏差不超过确认范围（如 ±2 ℃，以 OQ/PQ 为准） |
| 升温 | “有无异常” | 空载升温曲线不偏离确认范围；超温保护可动作 |
| 循环泵 | 无异响、无泄漏 | 补充：电流 / 压力 / 进出口温差、液位在标记区间 |
| 密封条 / 门 | 无破损 | 补充：闭合到位、无变形、无粘料；必要时真空保压试验代替目视 |
| 仪表 | 在校准有效期内 | 列出仪表位号、校准有效期，过期不得使用（GMP 第九十四条） |

不合格时现稿只在 7.4 写“立即停止操作并及时排除”。缺：

- 设备状态标识（待修 / 禁用）；
- 偏差 / 事件报告；
- 质量影响评估（本批及上次成功校准 / 保养之后的批次）；
- 谁有权放行再开机。

没有标准的检查表，在检查员眼里等于没有检查。

---

### 2.7 【严重】维修后放行、清洁、再确认整段缺失

GMP：

- 第七十九条：维护和维修不得影响产品质量；
- 第八十一条：经改造或重大维修的设备应当进行再确认，符合要求后方可用于生产；
- 附录《原料药》第六条：润滑剂、加热或冷却介质应避免与产品接触；第十条：清洁防止残留与交叉污染。

现稿 6.4～6.6 只说“按 SMP 执行、填记录”，没有本机落地要求：

1. 打开箱门、更换门封 / 视镜垫、动火或进入箱体后，必须按清洁规程清洁并检查清洁状态，必要时目检 + 擦拭残留；
2. 更换产品接触件（烘盘、密封条、视镜垫、快开卡箍垫）须走备件规格与变更 / 评估，材质不得降级；
3. 更换加热管、PLC/触控程序、真空泵主体、改变管路走向等，须评估再确认（真空泄漏、温度均匀性、连锁）；
4. 维修完成“试机正常”不能只由维修口头说了算，应有操作复核 + 必要的质量 / QA 放行。

7.4 还允许操作人员“及时排除”故障。操作工可以做的是停机、挂牌、通知；带压管路、电气、真空泵解体不属于操作岗“排除”。

### 3.2 设备概述科学性和边界有误

6.1.1 现文把真空降低沸点、加快干燥说清楚了，这是对的；后面“污染小，**故**不会对内在质量和形体造成损坏”不成立。

静态平板真空干燥相对转鼓、气流干燥，对晶体外形通常更温和，但仍然可以：

- 超温或局部过热导致降解、变色、晶型转变；
- 真空过猛造成物料喷溅、抽入真空管；
- 密封失效导致氧化、吸湿、溶剂回收失败；
- 箱体锈蚀、烘盘破损引入金属异物；
- 清洁不彻底造成交叉污染。

概述应写预定用途和能力边界，不要写保证性结论。建议改为：在确认的温度 / 真空范围内用于〔物料名称或工序〕的减压干燥；超出确认范围或带病运行时，不能保证产品质量。

另缺：设备编号、厂家、制造日期、加热介质、工作温度范围、工作真空度、防爆标志、与上下游（真空泵、冷凝器、热水站）的接口。

### 3.3 6.2.3 检查表结构失效，关键部件漏项

表中多行“检查内容”空白，靠合并单元格阅读。电子稿或复印后合并关系丢失，现场会漏检。应 **一行一部件、一栏标准、一栏结果、一栏备注**。

按平板真空干燥箱，日常 / 月度至少应能覆盖下表。括号内为现稿状态。

| 部件 / 系统 | 现稿 | 审核意见 |
|-------------|------|----------|
| 触控屏 / PLC | 有，与开关灯线混写 | 分开；补黑屏、死机、报警、记录功能（如有） |
| 控制开关 / 急停 | 开关有，急停无 | 急停复位与标识必须列入 |
| 指示灯 | 有 | 保留 |
| 动力线 / 接地 | 仅动力线 | 补接地螺栓、电缆破损、防爆挠性管（如防爆区） |
| 温度计 / 温控仪 | 有校准有效期 | 与 7.3“温控仪”统一名称；补传感器位号、超温保护 |
| 真空表 / 变送器 | 有 | 补量程、是否在校准计划内、指针是否回零 |
| 密封条 / 箱门 / 视镜 / 紧固件 | 有，但与箱体粘连 | 拆开；视镜灯 6.3 才出现，日常也应看是否能观察物料 |
| 箱体 | 有 | 补夹套 / 平板焊缝渗漏、保温层破损 |
| 液位 | 有，未说明是什么液 | 写清：循环热水箱 / 膨胀水箱液位 |
| 加热部件 / 加热平板 | 有 | 写清介质进出口、板面变形、与烘盘贴合 |
| 管线 / 循环泵 | 有 | 补压力表、过滤器、阀门开关状态 |
| 烘盘 | 有 | 补数量、编号、变形、与物料接触面光洁无锈 |
| **真空泵** | **无** | **必须补** |
| 真空阀 / 放空阀 / 气动阀 | 仅半年项有气动阀 | 日常看开关灵活性与泄漏 |
| 冷凝器 / 接收罐（如有） | 无 | 有则必须列入，防溶剂倒灌 |
| 过滤器（泵入口） | 无 | 防粉尘抽入泵腔 |
| 安全阀 / 真空破坏阀 | 无 | 按实际配置列入安全附件 |
| 连锁 | 无 | 门未关严能否抽真空、超温能否切断加热 |

“液位”单独成行却不写介质，检查员和操作工都会猜。结合循环泵与加热平板，应是热水系统液位，不是箱内物料液位。

---

### 3.4 半年度 / 年度保养过薄，且与日常表不对齐

6.3.1 只列四条，其中：

- 电加热、密封、视镜灯、气动阀：可以保留；
- 防爆离心机、水管：须改正名称并并入循环水系统；
- **未做真空泄漏试验**——这是真空箱半年度保养的核心性能项，不是可选项；
- 未做温度均匀性或与确认报告比对（年度至少评估是否需要复测）；
- 未做超温保护、急停、门连锁动作试验；
- 未做电气绝缘 / 接地检测（可用兆欧表，按电气规程）；
- 未规定密封条、视镜垫、泵油、过滤器的更换周期或更换判据（开裂、永久变形、保压不合格即换，而不是“看一下”）；
- 未规定热水系统水质、除垢、补水介质（应用工艺允许的水，避免结垢导致板面温度不均）。

6.3.2 年度保养 = “做完半年项 + 看外观和接线端子”，深度不够。年度至少增加：电气柜紧固与除尘、关键仪表校准计划复核、备件与润滑台账复核、确认状态评估（是否需要温度分布 / 泄漏复测）、计算机化系统备份与权限检查（如适用）。

6.3.1.4 的视孔灯、气动阀在日常表中不存在，说明两套清单不是同一台设备分解出来的，而是两段文字拼起来的。

---

### 3.5 安全附件与校准范围过窄

7.3 只写“真空表，温控仪”。GMP 第九十条要求生产和检验用仪表、记录和控制设备定期校准；第九十四条禁止使用过期失准仪表。

本机通常还应纳入校准 / 核查计划（以仪表台账为准）：

- 控制用温度传感器与超温保护（建议独立回路，不能只校一块显示表）；
- 真空表或真空变送器；
- 热水系统压力表（如有）；
- 记录仪 / 电子记录系统（如触控屏存曲线）；
- 安全阀（如承压热水或蒸汽侧属于安全附件，按特种设备或企业安全附件规程）。

“温度计”与“温控仪”在 6.2.3 和 7.3 用词不统一，现场会只校玻璃温度计、不校控制探头。

---

### 3.6 触控屏未按计算机化系统管理

6.2.3 把触控屏写成“部件是否完好”。ICH Q7 5.40～5.48 及国内检查实践要求：GMP 相关计算机化系统应有操作和维护规程，变更受控，防止未授权修改。

若该屏仅作按钮替代、不保存批数据，可在确认文件中定义为低影响，但仍应规定：

- 不得擅自改设定参数范围、PID、报警限；
- 参数修改走变更或经批准的工艺指令；
- 故障黑屏时的应急（是否允许用手操旁路，旁路是否需QA）；
- 如保存历史曲线，应有备份与时间同步。

现稿完全沉默。原料药干燥温度 / 真空常是关键工艺参数，屏上改限值等于改工艺。

---

### 3.7 产品保护、润滑与异物

全文未提：

- 保养时箱内有无物料、如何隔离；
- 工具、垫片、螺钉清点，防止落入烘盘；
- 润滑剂品牌 / 食品级或相当级别、加注点、加注量、严禁加到产品接触面（GMP 第七十七条，附录《原料药》第六条）；
- 循环水泄漏进入箱体的应急（平板穿孔是这类设备的真实故障）。

6.2.3 已写“加热平板未出现跑冒滴漏”，说明作者知道平板内走液体，却没有写漏进箱体后的质量处理。

---

### 3.8 7.4 把操作规程内容塞进维护规程，且扩大操作工维修权

“设备运行时操作者不得离岗”属于 **设备操作 SOP**，不是维护保养 SOP。混写会导致两份文件打架（操作规程若允许巡检离开，本文件又不允许）。

“发现故障立即停止并及时排除”中的“排除”，应改为：停机、破空或卸压（按操作规程）、挂牌、报告。操作人员可处理的限度应列出（如复位急停、关闭阀门），其余通知设备维修。

---

### 3.9 相关文件与记录体系未形成闭环

现稿只点了三份记录 + 一份 SMP。至少还应关联：

| 文件 | 作用 |
|------|------|
| 本机操作规程 | 开停机、抽真空、破空顺序（先关真空阀再停泵，防返油） |
| 本机清洁规程 / 清洁验证 | 维护后清洁 |
| 设备运行 / 使用日志 | ICH Q7 6.20 使用日志含维护状态 |
| 仪表校准规程与台账 | 7.3 的落点 |
| 偏差、变更、确认与验证 SMP | 故障影响与再确认 |
| 安全 / LOTO / 防爆区作业规程 | 7.1 的落点 |
| 备件与润滑清单（附件） | 可执行 |

043 与 044 建议在本规程中用一张表界定栏目，避免“日常记录里做预防性项目、预防性记录里再打一遍钩”。

## 6. 建议关闭顺序

按检查风险，建议按下列顺序改，不要先润色文字：

1. **现场核对 P&ID / 铭牌 / 确认报告**：加热路径、真空泵型号、有无冷凝回收与防爆、仪表位号。先改系统名称，再改表。
2. **改范围与文件控制**：锁定 6 号机；补编号、依据、定义、相关文件。
3. **拆分日常点检 / 月度 / 半年度 / 年度**，重做两张记录的栏目，消灭 043/044 重叠。
4. **补真空系统、连锁、校准清单、合格标准**。
5. **补故障、偏差、清洁放行、重大维修再确认、LOTO**。
6. **改 7.1 / 7.4**，操作要求退回操作 SOP，本文件只保留维护相关安全。
7. **QA 组织对照修订稿走一次纸面演练**（拿空表按真实开机顺序勾选），再批准。

配套记录建议同步修订，否则只改 SOP、表还是“完好 / 正常”四字，问题仍在。
