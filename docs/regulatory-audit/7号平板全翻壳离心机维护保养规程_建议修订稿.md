## 1 目的

规范原料药车间 7 号平板全翻壳离心机的日常点检、月度保养、定期预防性维护及维修后放行，使设备持续符合预定用途和确认状态，防止机械伤害、燃爆、污染和交叉污染。

## 2 范围

2.1 适用于设备编号〔EQ-×××〕、型号〔〕的 **7 号平板全翻壳离心机** 及其机盖 / 〔翻壳〕机构、传动、减振、电控、氮气惰化（含〔制氮机 / 管网氮气〕）和安全联锁。

2.2 不替代操作规程、清洁规程、确认 / 再确认、校准规程。启停、氮置换、进料、卸料、破惰化顺序以操作规程为准。

2.3 其他离心机不得套用本记录编号。

## 3 职责

3.1 **生产部操作人员**：每次使用前及运行中点检；按操作规程监护；完成月度保养中的外观、漏油、滤布目视、机盖锁紧目视；发现异常停机、标识、报告。不得手盘转鼓、加注轴承脂、调整皮带、拆氮气管或打开电气柜。

3.2 **生产班长 / 车间负责人**：协调保养窗口；审批提前保养；禁止在箱内有物料或未隔离时开盖保养。

3.3 **设备工程部维修人员**：实施半年度 / 年度 PM 和维修；润滑、皮带、联锁试验、氮气检漏；提出再确认需求。

3.4 **设备工程部**：维护台账、备件、PM 计划，监督技术执行。

3.5 **计量**：氧含量仪、压力表、〔振动仪、转速表〕按计划送校，过期停用标识。

3.6 **QA**：批准本规程及变更；抽查执行；审核偏差、变更、再确认；对联锁失效、氧含量仪超期、带病运行拥有否决权。

## 5 定义

5.1 **日常点检**：每次使用前及运行中的状态确认，不替代定期维护。

5.2 **预防性维护（PM）**：按计划检查、清洁、润滑、试验和到期更换。

5.3 **重大维修**：可能改变确认状态的维修或改造，包括但不限于：更换转鼓或主轴承、重新动平衡、改变频器最高转速或加减速、改开盖 / 氧含量 / 振动联锁逻辑或设定值、改氮气回路、焊接产品接触面。须评估，必要时再确认。

5.4 **再确认**：重大维修或改造后证明仍符合预定用途方可投产。

5.5 **产品接触面**：转鼓内表面、滤布 / 滤网、壳体内侧、机盖内侧、进料 / 洗涤管出口、出液通道及接触物料的密封件。

5.6 **零转速**：转鼓已完全停止。确认方法：〔观察窗确认 + 等待不少于制动时间 t 秒 + 变频器 / 测速显示 0〕，不得仅凭“声音变小”。

5.7 **安全销**：开盖检修时插入、阻止机盖落下或误关的机械销。与运行锁紧插销不是同一使用状态。

5.8 **惰化**：用氮气将腔内氧含量降至并维持在〔≤ x%〕，并保持微正压〔〕。

5.9 **锁定挂牌（LOTO）**：切断并验证电源、气源、〔液压〕能量，挂锁挂牌后检修。

## 6 设备概述

6.1 **预定用途**：在确认的最高操作转速〔〕r/min、装载量〔〕、滤布规格〔〕、氧含量〔≤ x%〕范围内，对〔工序 / 物料〕做固液分离。超出确认范围须先变更评估。

6.2 **工作原理**：转鼓由电机经〔皮带〕驱动旋转，固相截留在滤布上，母液由出液口排出。溶剂工况下须先氮气置换至氧含量合格，运行中维持氮封；减振装置衰减振动，不能理解为“必然无振动”。固体按本机型式〔上部开盖取出 / 翻壳卸出〕。

6.3 **系统组成（与现场不符的行划去）**

| 系统 | 组成 |
|------|------|
| 机体 | 平板底座、外壳、机盖、锁紧插销、安全销、视镜及视孔灯、减振器、地脚 |
| 转鼓 | 转鼓、滤布 / 滤网及压条或涨圈、拦液板 |
| 传动 | 电机、皮带及带轮、轴承座、〔制动器〕、变频器 |
| 卸料 | 〔上部人工卸料〕〔液压大翻盖〕〔全翻壳油缸、机械锁、翻转限位〕〔刮刀〕 |
| 工艺接口 | 进料、〔洗涤〕、出液、排气、氮气管 |
| 惰化 | 〔制氮机或管网〕、过滤器、气动 / 电磁阀、氧含量仪、压力表 / 变送器、微正压维持、泄放 |
| 控制与安全 | 电控柜、急停、开盖联锁、过振动保护、电机保护、〔料满〕、指示灯 |

## 7 通用要求

7.1 **分级作业**

| 类型 | 允许 | 禁止 |
|------|------|------|
| 点检 | 外观、漏油、读数、闭盖状态下确认联锁指示 | 开盖伸手进鼓；未惰化启转 |
| 空载功能检查 | 空鼓、闭盖锁定、氮置换合格后按操作规程点动或升至点检转速 | 当作无记录的“转一下” |
| 开盖检修 | 零转速 + 断电 LOTO + 安全销 + 空鼓或物料已隔离 | 开盖状态点动主机；用身体强行压盖 |
| 氮气检修 | 泄压、关气源、验压、挂牌 | 带压拆管 |

7.2 运转中及未确认零转速前，禁止手接触转鼓、取料、换滤布。探身入鼓按〔有限空间〕管理，注意氮气窒息和溶剂蒸气。

7.3 润滑脂为〔食品级或相当，牌号〕，只允许加在规定点。轴承座或液压油漏入产品接触面：停用，偏差评估，清洁验证或按清洁规程处理。

7.4 滤布、密封圈、安全销须用批准规格。换滤布记入 041 或 029，双人复核安装。

7.5 工具、销、螺钉带入转鼓须计数。掉入鼓内按偏差处理，禁止闭盖试转“找东西”。

7.6 氧含量联锁阈值、最高转速、振动停机值不得擅自修改。程序或设定值结构性修改走变更。

7.7 未经校准、超期或失准的氧含量仪、压力表、振动保护不得用于生产和作为放行依据。

7.8 月度及定期保养只允许提前、不允许无故延后。生产期间同步保养不得打开产品接触面、不得加脂、不得拆氮气管。逾期按偏差处理。

7.9 旋转方向必须与机上箭头一致。重新接线或换变频器后第一次必须点动确认，禁止直接高速。

## 8 日常点检（每次使用）

8.1 责任：操作人员。记录：〔042 点检栏或批记录 + 运行日志〕。

8.2 **使用前（启转前）**

8.2.1 状态为“清洁 / 可用”，无待修挂牌；氧含量仪及其他附表 2 仪表在校准期内。

8.2.2 外观完整，安放平稳；地脚 / 地面定位标记无位移；外表面清洁干燥、无锈。

8.2.3 轴承座、电机、〔液压站〕无漏油、漏脂。

8.2.4 机盖密封圈无破损外露；闭盖后锁紧插销到位，开盖联锁指示为“盖已关”；安全销在规定存放位（运行时不得插在开位锁死）。

8.2.5 滤布无破损、无脱落，压条 / 涨圈到位；转鼓内无工具、无上批残留（按清洁状态）。

8.2.6 出液口、视镜畅通清洁；急停无遮挡。

8.2.7 氮气压力〔〕，管路无泄漏；氧含量仪上电能显示，无故障报警。

8.2.8 皮带防护罩完好（目视，不开罩）。

8.3 **按操作规程启动（不属于“无条件日常转车”）**

8.3.1 闭盖锁定 → 氮置换 → 氧含量 ≤〔〕% 且微正压〔〕 → 允许启动信号存在，方可启动。

8.3.2 升速过程听异响、看振动、看电流 / 转速。超振动、异响、氧含量回升立即按操作规程停机。

8.3.3 点检不得以“开盖后点动转鼓是否灵活”代替。灵活性检查只允许在第 7.1 开盖检修条件下由维修手盘。

8.4 **运行中**：监护转速、振动、氮封、有无泄漏、出液是否异常。劳动组织以操作规程为准；分离高速阶段必须有人可立即急停。

8.5 **停机后**：按操作规程制动并确认零转速 → 解除惰化或按规程置换 → 开盖卸料。切断不需要的驱动电源。未清洁前按清洁规程标识。

## 9 月度保养

9.1 责任：操作人员为主，维修巡检签字。记录：REC-EQ-430-042（建议表名改为《7号平板全翻壳离心机月度维护保养检查记录》）。

9.2 在第 8 章基础上增加（空鼓、停机、需要开盖时执行 7.1）：

9.2.1 清洁外表面；检查机盖密封、底座密封外缘；检查插销、安全销有无弯曲裂纹。

9.2.2 检查减振器外观、地脚螺栓有无松动（力矩异常报维修）。

9.2.3 目视皮带防护罩外有无橡胶粉末（提示皮带磨损）。

9.2.4 核对氮气管接头、软管老化；氧含量仪显示与最近校准状态。

9.2.5 滤布使用状况、备件库存。

9.2.6 维修人员：空载、闭盖、惰化合格后，在〔点检转速〕短时运行，记录有无异响；读取振动〔测点〕是否 ≤〔〕；不得月月无条件高速空转。

9.2.7 复核仪表校准有效期；关闭上次缺陷。

## 10 定期预防性维护

10.1 责任：维修为主，操作为辅。记录：REC-EQ-430-041。操作复核关键联锁后更新状态标识。

### 10.2 半年度

10.2.1 完成第 9 章。

10.2.2 **转鼓与轴承（LOTO + 安全销 + 空鼓）**：手盘转鼓，听轴承、感觉卡滞；按附表 3 加注润滑脂；检查转鼓有无裂纹、严重腐蚀、滤孔变形、紧固防松。

10.2.3 **密封**：上盖密封圈、底座密封圈无裂纹、永久变形；不良则更换批准规格，禁止乱涂密封胶。

10.2.4 **紧固与基础**：机体防松件、地脚、带轮锁紧；减振器老化更换。

10.2.5 **皮带**：裂痕、磨损、油污、张紧〔挠度〕、轮槽对齐。不合格更换，换后点动确认转向。

10.2.6 **电控与保护**：急停、视镜灯、电机保护；做开盖联锁试验（盖未关不能启动；试验方法不得在高速时掀盖）；做振动保护功能检查（按厂家方法模拟或用便携振动源，不得破坏探头）。

10.2.7 **制动**：从〔〕r/min 停至零转速时间 ≤〔〕s。

10.2.8 **氮气**：阀门动作、管路泄漏、过滤器、排水；氧含量联锁动作试验（模拟或标准气，使读数高于〔〕%，确认禁止启动 / 报警）；微正压维持。

10.2.9 **〔翻壳 / 大翻盖液压〕**：油位、泄漏、限位、机械锁、防坠落撑杆。

10.2.10 **滤布安装结构**：压条、涨圈、卡箍腐蚀与松动。

### 10.3 年度

10.3.1 完成 10.2。

10.3.2 电控元器件外观；断电 LOTO 后紧固接线端子；电机及壳体接地、管道跨接导通；必要时测绝缘。

10.3.3 制氮系统电磁阀、管路泄漏；〔制氮机过滤器、活性炭 / 分子筛、储罐排水〕按厂家周期。

10.3.4 变频器参数、最高转速限制与确认版本一致并备份。

10.3.5 转速显示与手持转速表比对，偏差 ≤〔〕。

10.3.6 评估轴承、转鼓动平衡、振动趋势；达到触发条件则申请再确认或动平衡。

10.3.7 全套安全附件校准证书复核；联锁清单签字。

10.3.8 备件：滤布、密封圈、皮带、安全销、〔氧探头〕。

## 11 不合格、维修与放行

11.1 不合格：停止用于生产，挂“待修 / 禁用”，报告班长和设备工程部。可能影响已分离物料的，按偏差评估。联锁失效、氧含量仪失准、转鼓异响、严重振动：**立即停用**。

11.2 操作人员允许：按规程停机、等待零转速、急停、关闭进料和氮气（按操作规程）、报告。不允许：手盘、加脂、调皮带、拆氮气管、旁路联锁、带电开柜。

11.3 维修填 REC-EQ-100-029，执行 SMP-EQ-100-003。箱内有物料时先按规定卸料或隔离。

11.4 维修后：清点工具；按清洁规程清洁受影响的产品接触面；撤 LOTO；按操作规程做闭盖、惰化、空载试机（转向、异响、振动、氧含量联锁）；维修人、操作人签字，需要时 QA 复核；更新标识和运行日志。

11.5 重大维修：先变更评估，再确认合格前不得投产。“试机正常”不能替代再确认。

11.6 氧含量仪或其他关键仪表校准超差：停用该仪表，调查上次合格校准至发现超差期间的生产，评估质量与安全。

13.2 氮气检修：泄压、关源、验压；注意窒息；泄压后挂牌。

13.3 〔溶剂防爆区：使用防爆工具，保持跨接，禁止非防爆电器带入。〕

13.4 长期停用：清洁、滤布按规程处理、断电、氮气管关闭、防锈；再启用前按月度 + 联锁试验 + 转向点动。
