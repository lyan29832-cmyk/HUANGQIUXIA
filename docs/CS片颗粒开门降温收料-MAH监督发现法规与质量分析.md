# cs片颗粒“开门降温、面板温度收料”MAH监督发现

## 法规符合性、工艺科学与质量体系深度分析

**文件性质：** 审计/质量专家意见（基于现有偏差表“原因/评估”截图及MAH现场监督描述）  
**分析立场：** 持有人监督检查、注册工艺一致性、确认与验证、质量风险管理  
**分析日期：** 2026-09-04  
**对应批次：** 202608 批 cs 片颗粒（现场观察日期 2026-09-01）

## 一、发现原述与图片记载的对应关系

### 1.1 MAH 现场监督发现（问题原貌）

2026年9月1日，操作人员对 **202608 批 cs 片颗粒** 干燥 **5 小时** 后取样检测干燥失重，结果符合规定后：

1. 停止烘箱加热；
2. **打开箱门降温**；
3. **待设备面板显示温度降至约 40℃** 时开始收集颗粒。

MAH 认定：上述 **开门降温方式**，以及 **以设备面板温度作为收料判定条件** 的合理性，**未经风险评估和确认或验证**，**无法证明该过程持续受控**。

### 1.2 现有表格已写内容（图片）

| 栏目 | 原文要点 | 专家即时判断 |
| --- | --- | --- |
| **原因** | cs 片颗粒生产工艺验证过程未识别出“开门降温方式”的风险，验证过程未纳入验证范围。 | 仅陈述“未验证”这一事实，**不是根本原因**，且只覆盖“开门降温”，未覆盖“面板温度作为收料标准”。 |
| **评估** | 对产品质量潜在影响：**有**。开门降温至约 40℃ 可能导致颗粒干燥失重偏高或不合格；未有验证数据证明该方式合理性。 | 影响方向判断正确（LOD），但 **风险面过窄**，未评估面板温度与物料温度不等效、环境吸潮季节性、后续压片/稳定性/微生物、注册工艺一致性及历史批次。 |

**结论先行：**  
现有“原因/评估”方向不错，但按国内外检查尺度，属于 **浅层、不完整的偏差评估**。若以此回复 MAH，极易被二次追问：“为何验证方案未纳入？SOP/批记录是否写了？注册工艺有没有这一步？历史批次怎么证明没问题？”

## 二、问题拆解：这不是一个点，而是三条相互独立的缺陷

检查员实际打的是 **组合拳**。必须拆开写，否则 CAPA 会对错对象。

| 编号 | 缺陷本质 | 现场事实 | 质量含义 |
| --- | --- | --- | --- |
| A | **工艺步骤未识别 / 未纳入验证范围** | 干燥终点后的降温、开箱、收料未作为独立工序进行确认或验证 | 工艺理解不完整，PPQ 不能代表商业生产全流程 |
| B | **判定标准缺乏科学依据与计量学基础** | 以 **设备面板显示温度约 40℃** 作为开始收料条件 | 面板温度 ≠ 物料温度 ≠ 干燥失重；“约”不是工艺标准 |
| C | **过程未证明持续受控（CPV/持续工艺确认缺失）** | 开门幅度、环境温湿度、冷却时间、装量、季节差异均未受控、未监测 | 即使单批 LOD 合格，也不能证明工艺稳健、可重复 |

三条之中，**B 往往比 A 更致命**：即使补做一次“开门降温”确认，如果仍用面板温度当收料标准，科学上仍然站不住。

## 三、工艺科学分析（检查员真正在看什么）

### 3.1 干燥终点与收料状态不是同一个质量状态

现场逻辑是：

> 干燥 5 小时 → 取样 LOD 合格 → 停热开门 → 面板约 40℃ → 收料

这在制剂工艺上是一个典型误区：**把“干燥终点的 LOD”当成“收料时的 LOD”。**

- 取样发生在 **密闭、仍处于热态** 的箱体内；
- 收料发生在 **箱门已开、物料已与洁净区空气进行热湿交换** 之后；
- 两者之间存在一个 **未表征的保持/冷却窗口**。

因此，5 小时 LOD 合格，只能证明 **当时、该取样点** 的水分符合规定，**不能外推至收料、过筛、总混、压片前的水分状态**。

### 3.2 开门降温的真实物理过程

烘箱门打开后，同时发生至少四类过程：

1. **对流传热：** 热空气迅速逸出，室内空气进入；面板/腔体空气温度下降很快。  
2. **对流传质（吸潮或继续干燥）：**  
   - 若颗粒仍热、表面水活度低于环境，可能继续失水；  
   - 更常见的是：**热颗粒 + 相对较湿的室内空气 → 吸附水分，LOD 升高**。  
   吸湿性辅料（淀粉、糖粉、微晶纤维素、中药浸膏颗粒等）对这条路径尤其敏感。  
3. **温度场失真：** 门区、托盘边缘、料层表面降温快，料层内部、托盘中心降温慢。  
4. **污染与交叉污染路径打开：** 人员、气流、微粒、微生物由开门引入。

因此，图片中“可能导致干燥失重偏高或不合格”是对的，但只写了 **湿度风险的一半**。完整说法应是：

> 开门降温可能使 LOD **升高（吸潮）或继续降低（余热赶水）或批内不均匀**，方向取决于环境温湿度、开门程度、冷却时间、装载量和物料吸湿性；**目前没有任何数据能证明净效应受控。**

### 3.3 以设备面板温度约 40℃ 作为收料条件，科学上不成立

这是本发现的技术核心。

| 问题 | 说明 |
| --- | --- |
| **测点对象错误** | 面板温度通常为腔体空气、加热器附近或控制用传感器温度，**不是物料温度、不是料层核心温度**。开门后空气温度可在数分钟内掉到 40℃，物料仍可能显著高于或低于该值。 |
| **传感器位置未确认** | 无温度分布确认（temperature mapping）时，无法证明该显示值代表任何有质量意义的位置。 |
| **“约 40℃”不是工艺参数** | GMP 工艺参数必须有目标值、范围、检测方法与超限处理。“约”意味着操作员主观判断，批间不可比。 |
| **40℃ 的来源未论证** | 常见经验理由包括：便于手触收料、减少包装结露、避免烫手。这些属于 **职业安全/操作便利**，不能自动成为 **CQA 控制策略**。必须用物料温度、LOD、后续可压性、微生物来论证。 |
| **不是干燥终点的替代指标** | 干燥终点已用 LOD 判定；冷却/收料若再用温度，必须证明该温度与 **收料 LOD、均匀性、后续工序** 相关。目前无相关关系数据。 |

**审计表述建议：**  
“以设备面板显示温度作为收料判定条件，属于用不具代表性的设备状态参数替代物料质量属性，不能证明收料过程受控。”

### 3.4 对后续工序与产品生命周期的连锁影响

LOD 不是孤立指标。水分偏移可能传导至：

- **总混：** 含量均匀性、流动性；  
- **压片：** 粘冲、松片、裂片、硬度、脆碎度、片重差异；  
- **溶出/释放：** 水分改变颗粒孔隙与崩解行为；  
- **微生物：** 水分升高缩短干燥状态的抑菌优势；  
- **稳定性：** 水解敏感成分、中药浸膏吸潮结块、杂质增长；  
- **包装：** 热料入袋结露，相当于二次加湿。

图片评估只写到“LOD 可能不合格”，在检查回复中会被认为 **未评估至患者和注册质量标准层面**。

### 3.5 变异源：为何“无法证明持续受控”

即使 202608 批最终合格，下列变异源未锁定：

- 洁净区温湿度（季节、空调工况、开门当日 RH）；  
- 开门角度、开门时长、是否完全打开；  
- 装载量、托盘层数、料层厚度；  
- 取样点与收料点是否同一位置；  
- 操作人员差异；  
- 烘箱控制传感器校准状态；  
- 冷却期间是否有人员频繁进出、是否有其他热源/湿源。

这些正是 FDA 2011 工艺验证指南所说的 **critical sources of variability**。未识别、未控制、未监测，即 **Stage 3 持续验证失败**，也符合中国 GMP 附录《确认与验证》中“持续工艺确认”的缺口。

## 四、对图片中“原因”的批判性评价与重写

### 4.1 现有原因为什么不够

原文：

> cs 片颗粒生产工艺验证过程未识别出“开门降温方式”的风险，验证过程未纳入验证范围。

缺陷：

1. **循环论证：** 检查发现就是“未验证”；把发现复述一遍，不是根因。  
2. **范围残缺：** 未写“面板温度收料标准”。  
3. **未回答 Why：** 为何方案设计时没纳入？是工艺描述缺步骤，还是风险评估模板不含“干燥后处理”，还是把收料当成“辅助操作”而非工艺步骤？  
4. **未区分体系责任：** 验证、工艺开发、QA 方案审核、MAH 对受托生产的工艺监督，责任链不清。  
5. **未区分文件状态：** 该操作是写在 SOP/批记录里但未验证，还是现场习惯、批记录未记录？两种性质完全不同。

### 4.2 建议的根因分层（检查回复可用）

**直接原因（Direct cause）**  
干燥结束后的降温与收料未作为独立工艺步骤进行质量风险评估，关键工艺参数（或关键操作条件）未识别；工艺验证/确认范围仅覆盖加热干燥及 LOD 终点，未覆盖降温方式、收料判定、环境条件及物料实际状态。

**根本原因（Root cause，建议 5-Why）**

1. 为何未纳入验证？  
   → 工艺验证方案的过程步骤来源于工艺规程/批记录的“干燥”章节，该章节将“干燥合格”视为工序结束，未将 **停热、冷却、开箱、收料** 定义为影响 CQA 的步骤。  
2. 为何工艺规程这样写？  
   → 工艺开发/技术转移阶段未完成全流程过程图（process mapping）和 CPP/CQA 链接，降温/收料被当作“岗位习惯”或“设备操作”，而非工艺。  
3. 为何 QA 审核未拦住？  
   → 验证方案审核检查表偏重设备 IQ/OQ、干燥温度/时间/LOD，**无“工序完整性（从投料到中间产品接收）”强制项**。  
4. 为何日常生产能这样操作？  
   → 批记录收料条件写“约 40℃”或未定量，现场以面板温度为准，偏差/变更体系未将其识别为“未经确认的操作”。  
5. 体系根因：  
   → **质量风险管理未贯穿工艺全生命周期**（ICH Q9），工艺验证停留在“做三批合格”而非“证明变异源受控”（ICH Q8/Q10 + FDA PV 2011 + 中国 GMP 确认与验证附录）。

**系统性问题（需在 CAPA 中承认）**  
该缺口很可能不是 cs 片独有。凡“烘箱/热风循环烘箱干燥后开门冷却收料”的品种，都可能存在同样的验证盲区。建议作为 **同类工艺横向回顾** 的触发点，否则检查员会问“别的产品呢？”

## 五、对图片中“评估”的补全

图片已勾选“对产品质量的潜在影响：**有**”，这一勾选 **正确，必须保持**，不可改为“无”。

建议评估结构改为四段，而不是只写 LOD。

### 5.1 对产品质量的潜在影响：**有**

**CQA 层面**

- 颗粒干燥失重（LOD）可能升高、降低或批内不均匀；  
- 可能影响颗粒流动性、可压性、片剂硬度/脆碎度/溶出；  
- 对湿热敏感成分存在降解/微生物风险（需结合处方论证）。

**科学依据**  
开门后物料与环境进行热湿交换；面板温度不能代表物料温度与水分。无确认数据证明该操作窗口内 CQA 保持在已验证状态。

### 5.2 对注册工艺/放行标准的符合性影响：**有（程序与数据层面）**

- 若注册工艺未载明“开门降温 + 面板 40℃ 收料”，则存在 **实际生产与批准工艺不一致** 的嫌疑；  
- 若注册/工艺规程写了但未验证，则属于 **关键步骤缺乏验证**；  
- 中间产品放行若仅依据干燥 5 小时 LOD，未代表收料状态，则 **放行检验不能完全覆盖该风险**（取决于是否有收料后/总混前复测 LOD）。

### 5.3 对已生产批次的影响（回顾性）

在完成下列证据前，**不能简单写“无影响”**：

1. 202608 批：收料后、总混后、成品的 LOD/水分及相关质量指标；  
2. 历史商业批次：干燥后至压片前的水分趋势、偏差、OOS、压片粘冲/硬度异常；  
3. 生产当日洁净区温湿度记录；  
4. 批记录中开门至收料的时间、面板温度记录是否存在、是否可追溯。

若收料后或成品 LOD 仍合格、且无相关偏差趋势，可评估为 **潜在影响存在，但本批及回顾批次未观察到不良质量后果**——这是检查上可接受的表述；**不要写成“无潜在影响”**。

### 5.4 对患者安全

在处方非强吸湿、非强水解、成品检验覆盖水分/溶出/微生物、且回顾数据未显示偏移时，患者安全风险通常可评估为 **低，但不可忽略**。最终分级应在收集数据后用 FMEA/风险矩阵给出，而不是在偏差表里口头判断。

## 六、法规符合性对照（中国 + ICH + FDA + EU + PIC/S + WHO）

本发现可同时映射为：**验证范围不足、关键工艺参数未识别、实际操作缺乏科学标准、持续受控无法证明、可能偏离注册工艺。** 以下按检查员最常用的条款组织。

### 6.1 中国（本发现的直接管辖）

| 法规/文件 | 相关要求 | 与本发现的对应 |
| --- | --- | --- |
| 《药品管理法》及 MAH 制度 | 持有人对药品质量承担主体责任；对生产过程进行监督 | MAH 本次监督合法且应当发现此类工艺不受控问题；企业不能以“历来如此”抗辩 |
| 《药品生产质量管理规范（2010 年修订）》 | 生产应按批准的工艺规程进行；工艺规程应规定工艺参数、中间控制；任何影响质量的偏差应调查 | “约 40℃、看面板、开门降温”若未在批准工艺中明确规定并受控，即工艺规程不完整或未执行 |
| GMP 附录《确认与验证》 | 确认和验证的范围、程度应通过 **风险评估** 确定；工艺验证应证明能 **持续稳定** 生产符合预定用途和注册要求的产品；应识别 **关键工艺参数**；应进行 **持续工艺确认** | 未风险评估就省略降温/收料；PPQ 未覆盖全流程；无法证明持续受控——与附录表述高度吻合 |
| 《药品 GMP 指南》确认与验证、口服固体制剂 | 干燥终点、水分、设备能力、装载方式均属常见关键要素；冷却、卸料应在工艺描述中明确 | 开门冷却属于干燥工艺的一部分，不是“设备附属动作” |
| 上市后变更/注册工艺一致性相关文件 | 生产工艺应与注册工艺一致；关键步骤、关键参数变更应按变更分类管理 | 若实际降温收料方式从未申报、从未变更评估，存在“静默工艺”风险 |
| 数据完整性（NMPA 相关检查要求，对齐 ALCOA+） | 操作应实时、准确记录 | 若批记录只写“降温至约 40℃”而无物料温度、环境湿度、开门时间，记录不能重建过程 |

**对中国检查的一句话定性：**  
这不是“操作不规范”的小问题，而是 **工艺验证生命周期不完整 + 关键操作条件未科学设定**，可按 **主要缺陷（Major）** 掌握；若同时发现批记录不记、多品种同样操作、有 LOD 超标或稳定性问题，可上升为 **严重缺陷**。

### 6.2 ICH（全球通用语言，MAH/国际 varietal 检查必用）

| 指南 | 要点 | 对应 |
| --- | --- | --- |
| **ICH Q8(R2)** 药物研发 | 应理解物料属性、工艺参数与 CQA 的关系；CPP 是其波动会显著影响 CQA 的参数 | 降温方式、环境湿度、收料温度可能影响 LOD（CQA）；未被识别为 CPP/KPP |
| **ICH Q9(R1)** 质量风险管理 | 风险识别应覆盖全流程；未评估不等于无风险；控制措施应与风险相称 | 验证未识别开门降温风险，属于 QRM 失败，不是“风险不存在” |
| **ICH Q10** 药品质量体系 | 工艺表现与产品质量监控；知识管理；CAPA 应防止复发 | 持续受控无法证明 = PQS 的工艺监控失效 |
| **ICH Q11**（若涉及原料药中间体干燥，可类比） | 工艺设计和控制策略 | 控制策略缺少冷却/卸料要素 |

### 6.3 美国 FDA

| 依据 | 要点 | 对应 |

| **21 CFR 211.100** | 应有书面生产、过程控制规程；任何偏离应记录和说明 | 开门降温与面板温度收料应有书面、经批准的规程 |
| **21 CFR 211.110** | 应建立中间控制，监控产出并验证工艺性能，使物料符合标准和特性 | LOD 取样后仍发生显著操作，中间控制未延伸到收料状态 |

### 6.6 条款归纳（写给 QA 答辩用的“缺陷标签”）

建议在内部定性和给 MAH 的回复中，使用下列标签，避免只写“未验证”：

1. **工艺验证范围不完整**（中国 GMP 确认与验证附录；EU Annex 15；FDA PV Stage 2）  
2. **关键工艺参数/关键操作条件未识别**（ICH Q8；21 CFR 211.110）  
3. **质量风险管理缺失**（ICH Q9；确认与验证附录第三条）  
4. **控制策略与预定用途不匹配**（用设备面板温度替代物料质量属性）  
5. **无法证明持续受控**（持续工艺确认 / CPV / OPV）  
6. **可能的注册工艺执行偏差**（实际操作与批准工艺一致性，需核对申报资料）

## 八、即时遏制、批次处置与回顾（Containment）

在 CAPA 完成前，建议按下列顺序做，这是检查中“态度和体系”的加分项。

### 8.1 即时措施（24–72 小时量级）

1. **偏差/OOS 通道立案**（若尚未立案），与 MAH 发现闭环。  
2. **临时控制措施（必须书面）：**  
   - 禁止无记录、无温湿度控制的开门降温；  
   - 干燥 LOD 合格后，优先 **闭门冷却**（关闭加热、保持箱闭、必要时维持干空气/循环），或转移至已确认的冷却设备/冷却间；  
   - 收料判定改为 **物料温度（经确认的测点）+ 收料前 LOD**，取消“面板约 40℃”作为唯一标准；  
   - 记录开门起止时间、房间温湿度、物料温度、收料前 LOD。  
3. **202608 批：** 冻结后续放行决策，完成收料后水分、中间产品及成品相关项目评估后再决定放行或继续加工。  
4. **横向排查：** 所有烘箱干燥品种、近三年商业批。

### 8.2 202608 批评估要点

- 批记录：干燥参数、LOD 原始数据、降温/收料描述、时间点；  
- 收料后若已总混/压片：成品水分、硬度、溶出、有关物质/微生物（按标准）；  
- 与验证批、历史批均值比较；  
- 若仅有干燥中 LOD、无收料后 LOD：这是评估缺口，需在偏差中诚实写出，并用后续成品数据做间接论证，同时作为 CAPA 输入。

### 8.3 回顾性评价方法（可写进方案）

- 收集干燥终点 LOD、成品水分、压片过程参数、相关偏差；  
- 按季节（RH 高的月份）分层看趋势；  
- 若高湿季节水分明显偏高，即现场假设被数据证实；  
- 无能力做物料温度回顾时，不要编造，写“历史未采集，作为体系缺陷纳入 CAPA”。

## 九、确认/验证与控制策略（治本）

目标不是“补做一次开门降温的三批验证把错误做法合法化”，而是 **先评估该做法是否可接受，再决定是确认原方法还是改工艺。**

### 9.1 优先推荐的工艺路径（质量上更站得住）

1. **闭门冷却：** 停热后箱门保持关闭，待 **物料温度** 降至规定范围再开箱收料；必要时控制箱内湿度。  
2. **收料前复测 LOD：** 作为中间控制，证明冷却窗口未破坏干燥终点。  
3. **规定环境条件：** 开箱收料时房间温度、相对湿度上限。  
4. **规定时限：** 干燥终点至收料、收料至总混/压片的最长停留时间。  
5. **装载与开箱方式标准化：** 禁止“开多大门、开多久”靠习惯。

开门强制对流冷却只有在证明 **不吸潮、均匀、可重复** 后才可保留；对吸湿性颗粒，多数情况下应放弃。

### 9.2 若短期内仍需开门降温，最低确认包

确认（confirmation）可以先于完整再验证，但须有方案、有预定义接受标准：

- 最差条件：最大装量、最高环境湿度（或挑战湿度）、最常用开门方式；  
- 多点物料温度 vs 面板温度对照（开门前、开门中、收料时）；  
- 多点 LOD：开门前、收料时、料层上中下/内外；  
- 冷却曲线、开门时间；  
- 接受标准：收料 LOD 仍在内控；批内 RSD 可接受；面板温度与物料温度的偏差有明确限度——若偏差大，则 **否定面板温度作为判定条件**；  
- 后续压片关键质量属性。

**预期结果（专家判断）：** 面板温度与物料温度在开门后很可能 **显著偏离**。因此确认的科学结论多半是：**废除面板温度收料标准**，而不是给 40℃ 找一个勉强的“验证通过”。

### 9.3 文件应同步修订的清单

- 工艺规程、岗位 SOP、批记录模板（收料条件改为可记录、可复核的定量标准）；  
- 验证主计划、工艺验证方案/报告、持续工艺确认计划；  
- 风险登记册（FMEA）：干燥终点后冷却、开箱、吸潮、传感器代表性；  
- 注册工艺核对表；如实际工艺需保留开门降温，走变更分类；  
- 培训与再考核；  
- 设备：是否增加物料温度监控、箱内湿度、关门冷却程序。

## 十、给 MAH 的回复策略（专业、不辩解、可关闭）

### 10.1 原则

- **承认发现成立**，不要争“我们 LOD 合格所以没问题”。合格是检测结果，不是工艺受控的证明。  
- **承认图片中原因过浅**，主动升级为体系根因，检查员通常视为正面。  
- **潜在影响选“有”**，用数据证明“本批/历史批未观察到不良后果”，而不是改成“无影响”。  
- 给出 **临时措施 + 回顾计划 + 工艺确认计划 + 横向评估** 的时间表。  
- 避免承诺“保持开门降温并尽快验证通过”；应承诺“评估该方法是否可保留，不能证明则变更工艺”。

### 10.2 可直接用于偏差“原因”栏的改写稿

> cs 片颗粒干燥工艺将“干燥失重合格”视为工序终点，未将停热、冷却、开箱及收料识别为可能影响颗粒水分及其他 CQA 的工艺步骤。工艺开发与验证方案未开展覆盖全流程的过程图分析和质量风险评估，导致“开门降温”及“以设备面板显示温度约 40℃ 作为收料判定条件”未纳入确认/验证范围，亦未建立具有物料代表性的控制标准和持续监控。QA 对验证方案的审核未设置“工序完整性/CPP 识别完整性”的强制检查项，致使该缺口流入商业生产，无法证明该过程持续受控。

### 10.3 可直接用于“评估/说明”栏的改写稿

> 1）对产品质量的潜在影响：有。  
> 颗粒在 LOD 合格后仍经历开门降温与收料。开门使热颗粒与环境空气发生热湿交换，可能导致干燥失重升高、降低或不均匀，并可能影响后续总混、压片及稳定性。以设备面板温度约 40℃ 作为收料条件缺乏科学依据：该温度不代表物料温度，亦未与收料时 LOD 建立相关性，“约”不具备可重复的工艺标准。现有工艺验证数据不能证明上述操作窗口受控。  
> 本批及历史批次的实际影响，将依据收料后/成品水分及相关质量数据、环境温湿度记录进行回顾性评估后单独给出结论。

## 十二、结论

1. MAH 发现 **成立**，且表述准确：“开门降温方式 **以及** 以设备面板温度作为收料判定条件”均未经风险评估和确认/验证，**不能证明持续受控**。  
2. 图片中的原因把问题写成“验证没做”，属于 **直接现象**；真正的根因是 **工艺步骤识别失败 + QRM 失败 + 用设备状态参数冒充物料控制策略 + 验证审核未把关**。  
3. 图片中“可能影响 LOD”正确但不充分。科学上更关键的是：**干燥终点 LOD ≠ 收料 LOD**；**面板温度 ≠ 物料温度**；开门引入 **环境湿度这一未受控变异源**。  
4. 法规上，该问题可同时用中国 GMP 及确认与验证附录、ICH Q8/Q9/Q10、FDA 2011 工艺验证指南、EU/PIC/S Annex 15 定性，国际检查口径一致。  
5. 处置上应 **Major 缺陷、潜在影响有、先遏制再论证、优先改工艺而不是给不良习惯补验证**。202608 批用数据评估，不默认无影响，也不默认召回。  
6. 若只把开门降温补进验证范围、仍保留“面板约 40℃ 收料”，则 **技术上未关闭本发现**。
